# やり直しと連続練習の各回はプレイ画面のまま練習を作り直し、セットの状態はシミュレーションの外に持つ

状態: 承認

## 背景

練習中のやり直し（modes.md「やり直し」）と、回数を決めた連続練習（「連続練習（セット）」）では、プレイ画面のまま
同じ武器・モードで練習を始め直す。回と回のあいだに 3 秒の短いリザルトを挟み、最後か途中でやめたときにセットのまとめ
（`#/set-result`）を出す。練習は「開始」ごとに作り直す（2026-11-25-practice-session-per-start）が、やり直しと次の回では
ハッシュが変わらない。

## 決定

- やり直しと次の回は、画面に入り直さずに `startRound()` で World・入力のキュー・`PracticeSession`・ループを作り直す
  （開始ごとに作り直す決定を、回ごとに広げる）。弾痕も回の開始時に消す。打ち切った回は採点しない。
- セットの状態（回数・今の回・終えた回の平均ズレ・短いリザルトの締め切り）は `PracticeSet`（`src/ui/practice-set.ts`）に持ち、
  `src/sim/` には入れない。回数が 1 のときも 1 回のセットとして同じ経路を通し、終わればリザルト画面に移る。
- 短いリザルトの 3 秒はページの時計（`performance.now()`）で数える。シミュレーションのループは回の終わりで捨てる。
- 回の採点と自己ベストは 1 回分と同じ `completePractice` で回ごとに行い、`ResultView` に平均ズレと更新の有無を足して
  短いリザルトとまとめに使う。まとめは保存しない。`PracticeFlow` はまとめの有無だけを持ち、ないときは `#/set-result` をトップにする。

## 却下した案

- 回ごとに `#/play` に入り直す（ハッシュを一度変える）: 履歴に回の数だけ項目が積まれ、戻る操作で途中の回に戻ってしまう。
  プレイ画面のまま始め直すという SPEC とも合わない。
- セットを `src/sim/` の 1 つのシミュレーションで回を続けて進める: 回の境目で Gun・リコイル・入力の記録を戻す処理が要り、
  開始ごとに作り直す決定で避けた戻し忘れが起きる。記録と再生（INP-4）も回ごとに分けて扱える。
- 短いリザルトの時間をシミュレーションの時刻で数える: 回の終わりでループを止めるので、別のループを回すことになる。
