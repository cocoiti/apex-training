# フリックの的の並びは setup で種付きの乱数から 20 個分を決め、的は壁と的の箱より手前の、壁の正面と平行な板として置く

状態: 一部置き換え済み → [2026-11-27-humanoid-target-parts](2026-11-27-humanoid-target-parts.md)（的を板でなく人形として置く部分）

## 背景

Issue #74 のフリックは、1〜20 個目の的の出る位置の並びが同じ種・同じ出る範囲と的の大きさなら入力によらず一致する必要がある（MODE-49）。
的は照準の中心から決めた角度の距離に出て、壁の範囲に収まり、マップの的の箱と重なっても隠れない必要がある（MODE-50、docs/spec/modes.md「フリック」）。
モードのオブジェクトは練習ごとに使い回す（docs/adr/2026-11-25-mode-files-by-glob.md）。

## 決定

- `setup` で練習の乱数から 20 個分のずれ（Δyaw・Δpitch）をまとめて決める。1 個ごとに角度の距離・向きの傾き・左右の順に 3 つの乱数を取る。
  撃ったあとに次の的を決めるときは乱数を使わないので、撃つ時刻と照準によらず並びが変わらない。
- 的の中心は、目から「照準の中心 + ずれ」の向きのレイと、マップの箱のいちばん手前の面より 0.05 メートル手前の Z の面との交点に置く。
  奥行き 0.02 メートルの正方形の板で、幅と高さは 2 × L × tan(見込み角 ÷ 2)（L は目から中心まで）。マップは開始時の照準が -Z を向く前提。
- 練習ごとの状態（並び・撃った的の記録・調べ終えた弾の数）は、練習の `ModeContext` を鍵にした WeakMap に持つ。終わったあとの HUD（「的: 20 / 20」）も読めるよう、
  teardown では消さない。
- 撃った的の記録（時間・命中・ズレ）はモードの結果の `targets` に入れ、採点（`FLICK_SCORING`）はそれだけから求める。HUD の「的: n / 20」は
  モードの任意の `status` で出す。

## 却下した案

- 的を撃つたびに次の位置を乱数から決める: 並びは変わらないが、1 個目の的が出る前の弾など、撃ち方で乱数を取る回数が変わる処理を後から足すと並びがずれる。
  まとめて決めておけば、結果に並び（`offsets`）を入れて確かめることもできる。
- 板を視線に垂直に置く（見込み角がどの向きでもちょうどになる）: SPEC の「壁の正面と平行な板」と合わず、壁の上の的に見えない。
  壁と平行なので、照準の中心から遠い的ほど左右の見かけの幅がわずかに小さくなる（20 度で約 7%）。
- 状態をモードのファイルのモジュールの変数に持つ: 再生とテストで 2 つの練習を同時に作ると状態が混ざる。
