# リコイルは視点が跳ねる表示（カメラが動き、クロスヘアは中心のまま）だけにし、表示の方式を切り替える設定を作らない

## 状態

承認

## 背景

- これまでの実装は、カメラを「利用者の照準 + リコイルのオフセット」の向きに向け、クロスヘアを画面の中心に置いていた。
  撃つと壁・的・弾痕が画面上で下へずれる。SPEC には明記がなく、Issue #65 で保留していた「リコイルの見せ方」を決める。
- 比べた案は、カメラを利用者の照準に固定して弾痕やクロスヘアだけを動かす表示と、2 つを設定で切り替えること。

## 決定

- リコイルは Apex と同じく視点が跳ねる表示だけにする。カメラの向きは今のまま `viewAngles`（照準 + リコイルのオフセット）で、
  クロスヘアは CSS で画面の中心に固定する（`src/render/scene.ts`・`src/ui/style.css` は変えない）。
- 設定画面に表示の方式を切り替える項目を足さない。共通の設定の区分の項目も増やさない。
- UI-76 は、上向きの `pattern` で撃ったときに的の中心の投影が下へずれることと、クロスヘアの CSS・設定画面の項目で確かめる。

## 却下した案

- カメラを固定し、照準や弾痕だけを動かす: Apex の画面と見え方が変わり、練習した補正がゲームで同じ手の動きにならない。
  プロダクトの軸（パターンを覚えて Apex で同じ補正をする）に合わない。
- 2 つの表示を設定で切り替える: 練習の結果と履歴が表示の方式で比べられなくなり、設定の保存の形式（JSON の項目）も増える。
  パターンの形を見る手段は補正のパネルとリザルトの図ですでにある。
