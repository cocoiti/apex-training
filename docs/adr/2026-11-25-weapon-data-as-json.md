# 武器のリコイルは JSON のデータとして外に出す

状態: 承認

## 背景

公式のリコイルの数値はなく、出回っているのはコミュニティの計測などだけ。シーズンごとに武器の調整も入る。

## 決定

武器は `src/data/weapons/` の JSON 1 ファイルに 1 つ。`version`（対象のシーズン）と `source`（計測元）を持たせ、
ファイルを足すだけで選択肢に出るようにする。MVP の数値は形だけそれらしい仮のデータにし、`source` にそう書く。

## 却下した案

- コードに数値を直書きする: 差し替えや追加のたびにコードの変更が要り、どのシーズンの値かも分からなくなる。
- 外部のサイトから取得する: 公式の出典がなく、静的サイトのまま動かせなくなる。

## 影響

- docs/spec/weapons.md（WPN-1、WPN-2）
- src/data/weapons/
