# 練習は「開始」ごとに World・入力のキュー・シミュレーション・ループを作り直し、「開始」を押さずに開いた `#/play` はトップに戻す

状態: 承認

## 背景

練習の経過時間（HUD）と入力の時刻は「練習の開始からの秒」で、練習の終わりは撃った数と離してからの時間で決まる
（modes.md「共通」）。また「練習中でない状態で `#/play` を直接開いたときはトップ画面」（screens.md）でありながら、
「開始」のリンクの行き先も `#/play` である。前の練習の状態（時刻・リコイル・入力）を次の練習に持ち越さない方法と、
「開始」での遷移と直接開いたことを見分ける方法を決める必要がある。

## 決定

- 「開始」を押してプレイ画面に入るたびに、マップから World を作り直し、新しい入力のキュー・`PracticeSession`
  （Simulation・Gun・終わりの判定・モード）・固定ステップのループを作る。時刻はすべて 0 から始まる。
  3D のシーン（箱のメッシュ）は同じマップなので作り直さず、描画に渡す World だけを替える。弾痕は次の練習の開始時に消す。
- 「開始」のクリックで次のプレイ画面への遷移に印を付け（`src/ui/practice-flow.ts`）、印のないプレイ画面と、
  結果のないリザルト画面はトップ画面にし、ハッシュも `#/` に置き換える（置き換えないと「開始」でハッシュが変わらない）。
- 練習中にプレイ画面から離れたときは、その練習を打ち切り、結果を残さない。
- デバイスの入力は 1 か所の `emit` で今の練習のキューに積む。入力方式の切替はここで差し替える。

## 却下した案

- 1 つの Simulation とループを使い続け、練習の開始時刻を差し引く: Gun・リコイル・入力のキュー・ステップの数を
  すべて戻す処理が要り、戻し忘れが前の練習の状態を残す。
- 「開始」を `#/play?weapon=…` のようにハッシュに選択を載せる: 直接開いたときも練習が始まり、screens.md と食い違う。
- プレイ画面の表示だけをトップに切り替え、ハッシュは残す: 2 回目の「開始」で hashchange が起きず、練習を始められない。
