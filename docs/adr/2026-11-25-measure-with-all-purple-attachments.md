# 計測はアタッチメントをすべて紫にして撮り、外れた射撃は記録に理由を書いて平均から外し、未確認の条件は仮定として記録する

## 状態

承認

## 背景

- Issue #49 で C.A.R. SMG を、自分で撮影した射撃訓練場の動画（14 秒・3 回の射撃）からの計測値にする。
- アタッチメントを付けないと装弾数が少なく、マガジンの後半のリコイルが撮れない。L-STAR の撮影もすべて紫だったが、
  SPEC と記録は「アタッチメントなし」と書いていた。
- C.A.R. SMG の 3 回の射撃は、垂直の角度が 30 発目で 12.7〜16.2 度とばらつき、撮影者は「2 回目は少しずれたかもしれない」と申告した。
- FOV・壁までの距離・射撃中のスティックの操作は、撮影者に確かめられなかった。

## 決定

- 計測は、その武器に付けられるアタッチメントをすべて紫（レベル 3）にして撮る。武器データはその状態の跳ねを表し、
  アタッチメントによる反動の変化は扱わない。計測時のアタッチメントは武器データの `source` と計測の記録の `conditions.attachments` に書く。
  L-STAR の `source`・記録も「すべて紫」に直す（数値は変えない）。
- 平均から外す射撃は、計測の記録の射撃に `excludedFromAverage`（理由の文）を書いて示す。書かれていない射撃だけから
  `pattern`・`randomness`・許容差を求め、テスト（WPN-16・WPN-19）もその射撃だけで計算し直す。
  C.A.R. SMG は撮影者の申告とほかの 2 回からの差（垂直で最大 2.78 度）から 2 回目を外し、1 回目と 3 回目の平均にした。
- 撮影者に確かめられなかった条件は、L-STAR と同じ値（FOV 104・10 m・操作なし）を置き、記録の `assumptions` に書く。
  換算の式・相関を取る範囲の決め方は L-STAR（2026-11-25-lstar-measured-from-view-motion.md）と同じ。
- C.A.R. SMG は発射間隔が約 3.87 フレームでフレームの倍数にならないため、射撃ごとに跳ねの始まるフレームへ周期と位相を当てはめ、
  i 発目の跳ねが画面に出る直前のフレームの視点を i 発目の角度とした（L-STAR の「跳ねが収まったフレーム」と同じ意味）。

## 却下した案

- アタッチメントなしで撮る: 装弾数が少なく、全弾のパターンが撮れない。
- アタッチメントごとの反動の係数を武器データに持つ: 公式の数値がなく、計測もしていない。roadmap の未決定のまま残す。
- 3 回の射撃をすべて平均に使う: 2 回目が平均を上に引っ張り、許容差（垂直）が 1.1 度から 1.9 度に広がる。
- 統計の基準（平均からの差のしきい値など）だけで機械的に外す: 射撃が 3 回しかなく、2 回目と 3 回目の外れ方が同じ程度で決まらない。
  撮影者の申告を合わせて判断し、理由を記録に残す。
- 外した射撃を記録から消す: 判断を後から見直せない。
