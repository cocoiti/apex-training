# MVP から Three.js の一人称 3D で作る

## 背景

リコイル練習だけなら 2D の壁と弾痕で足りる。ただし将来キャラコン（移動練習）を入れる予定がある。

## 決定

Vite + TypeScript + Three.js で、MVP から一人称の 3D カメラで作る。リコイル練習は「カメラ位置を固定した、
壁と的だけの 3D シーン」にする。照準と弾道は最初から 3D のベクトル（ヨー・ピッチ → 方向ベクトル → レイの交差）で計算する。
UI は HTML/CSS をキャンバスの上に重ねる。

## 却下した案

- 2D（Canvas）で作り、キャラコンのときに 3D へ移す: 描画・座標系・入力をほぼ作り直すことになる。
- 物理エンジン（Rapier など）を最初から入れる: 当たり判定は箱・カプセルの自前の簡易判定で足りる。地形が複雑になってから検討する。
