# サーバーなしの静的サイトにし、画面はハッシュで切り替える

状態: 承認

## 背景

練習はすべてブラウザ内で完結する。公開先の候補の GitHub Pages はサブパス（`/apex-training/`）で配信され、
サーバー側のリダイレクトが使えない。

## 決定

- サーバー処理を持たない静的サイトにする。設定と自己ベストは localStorage に保存し、使えない環境でも練習はできるようにする。
- 画面の切替はハッシュ（`#/settings` など）で行う。データの読み込みパスはビルド時のベースパス基準にする。

## 却下した案

- 通常のパスでの切替（History API）: Pages で直接開くと 404 になる。
- サーバーで成績を保存する: MVP には不要で、運用の費用がかかる。

## 影響

- docs/spec/overview.md（OVR-3、OVR-4）、docs/spec/screens.md
- 公開の方法（GitHub Actions が使えない間のデプロイ）は未決定（docs/roadmap.md）
