# ブラウザ内の練習に限り、チートに転用できる出力とエイムアシストを作らない

状態: 承認

## 背景

リコイルのパターンや補正値は、マクロや Cronus 系のデバイス、RC フィルターの調整にも使えてしまう。
パッドのエイムアシストは内部の値が非公開で、2026 年もアンチチートの更新に伴って挙動が変わっている。

## 決定

- ゲームの起動中にマウスを自動で動かす機能、補正値のエクスポート、外部デバイスとの連携は作らない。
- エイムアシストは再現せず、「エイムアシストなしの素のリコイル制御を練習する」と UI に書く。
- EA / Respawn の素材を使わず、非公式のファンツールであることを常に表示する。

## 却下した案

- エイムアシストを近似で再現する: 正しい値が分からず、練習の結果を誤らせる。「的の近くで感度が落ちる」簡易オプションは未決定（docs/roadmap.md）。

## 影響

- docs/spec/overview.md（OVR-1、OVR-2、OVR-5）、docs/spec/pad.md（PAD-9）
- 将来のパターン編集の JSON エクスポートは、この決定と矛盾しない範囲を決めてから作る（docs/roadmap.md）
