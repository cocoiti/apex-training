# MVP の外の予定と未決定の事項

SPEC（`docs/spec/`）は今のプロダクトの仕様だけを持つ。ここには、まだ SPEC に入れていない予定と、決めていないことを置く。
取りかかるときは `/issue` で SPEC への変更として Issue にし、決めたことは ADR（`docs/adr/`）に残す。
背景の調査と参考リンクは [docs/proposal.md](proposal.md) にある。

## MVP の次に足すモード

- ダミー射撃: 人型のシルエット（自作の図形）に撃ち、ダメージと HS 率を表示する
- 移動ターゲット: 左右にストレイフする的を追いながら補正する
- パターン編集: 弾痕をドラッグして独自のパターンを作り、JSON で読み書きする。計測した数値を武器データにする道具にもなる。
  ADR「ブラウザ内の練習に限り、チートに転用できる出力とエイムアシストを作らない」と矛盾しない範囲（武器データの形式だけ、など）を決めてから作る

## キャラコン（移動テクニック）の練習

- ストレイフ撃ち、しゃがみ撃ち、スライド、スライドジャンプ、バニーホップ、壁ジャンプ、よじ登りジャンプ、
  スーパーグライド、タップストレイフ、ラーチ、移動しながらのリコイル制御
- 各テクの入力受付時間や速度はシーズンで変わるため、取りかかるときに最新の情報を調べてから決める
- 移動の数値は `src/data/movement.json` に外出しする

## 未決定

- リコイルの正確なデータの入手方法（射撃訓練場で自分で計測して JSON にするのが現実的）
- Apex の FOV の値（4:3 基準とされる。設定 110 ≒ 16:9 で約 120°）から水平視野角への正確な換算式
- アタッチメント（バレルなど）による反動の軽減の扱い（倍率の係数で簡易に対応する案）
- パッドのレスポンスカーブと速度の、実機との一致度（実機と見比べて定数を調整する）
- 「的の近くで感度が落ちる」簡易オプションを付けるか（付けるなら既定は OFF、「再現ではない」と明記する）
- ADS 倍率をスコープ別に設定できるようにするか
- 公開の方法: GitHub Actions は費用のため 2026-11-25 から止めている。Actions を使わずに GitHub Pages へ載せる方法か、別の置き場所を決める
- 将来: ジャイロ操作、パターン共有 URL
