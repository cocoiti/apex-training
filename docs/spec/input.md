# 入力の共通

## 概要

マウスとパッドの入力を、同じ「アクション」と「照準の角度の変化（度）」に揃える。リコイル・採点・描画は
入力方式を意識せず、角度だけを扱う。マウス固有の振る舞いは [mouse.md](mouse.md)、パッドは [pad.md](pad.md)。

## 用語

| 用語 | 意味 |
|------|------|
| アクション | 入力をキーやボタンではなく意味で表したもの。`look`（2 軸）、`fire`、`ads`。将来 `move`（2 軸）、`jump`、`crouch`、`sprint`、`reload` を足す |
| 入力の記録 | 1 回の練習の、時刻付きのアクションの列と乱数の種 |
| 照準の軌道 | 入力の記録から求めた、時刻ごとの利用者の照準（ヨー・ピッチ、度）の列。リコイルのオフセットは含まない |

## 振る舞い

### 入力方式の切替

- 設定で入力方式を「マウス」「パッド」「自動」から選べる。既定は「自動」。
- 「自動」のときは、最後に操作したデバイスの入力方式になる。
- 練習中に入力方式が変わったら、HUD に今の入力方式を表示する。

### アクションと時刻

- マウスとパッドのどちらからも、同じアクション（`look`・`fire`・`ads`）が出る。
- 各入力には発生時刻が付き、シミュレーションは固定ステップごとに、そのステップの時間内に起きた入力を消費する
  （[architecture.md](architecture.md)）。

### 入力方式ごとの保存

- 設定と自己ベストは入力方式ごとに別に保存し、マウスとパッドの成績を混ぜない。

### 入力の記録と再生

- 1 回の練習の入力を、練習の開始からの時刻付きで記録する。練習の開始時に乱数の種を 1 つ決め、シミュレーションの乱数はその種から取り、
  種も記録に入れる。
- 記録には、シミュレーションに積んだアクションを積んだ順にすべて入れる。
- 記録した入力は、記録を時刻の順にそのまま流す入力の元で再生する。再生では記録の種で乱数を作る。
- 記録した入力を、元の練習と同じ武器・マップで再生すると、同じ弾痕・同じ採点結果が再現される。ランダムなブレも、記録の種から同じものが出る。
  描画の間隔（フレームレート）が元の練習と違っても結果は同じになる。
- 種だけを変えて同じ入力を再生すると、ランダムなブレのある武器（`randomness` が 0 でない武器、[weapons.md](weapons.md)）では弾痕の位置が変わる。
- 記録はページの中（メモリ）だけで使う。ファイルへの書き出し、クリップボードへのコピー、外部への送信はしない。

### 記録の形

入力の記録は次の項目を持つ。

| 項目 | 型 | 意味 |
|------|----|------|
| `seed` | 0 以上 2³² 未満の整数 | 乱数の種 |
| `actions` | 配列 | 時刻付きのアクションの列（積んだ順） |
| `actions[].time` | 0 以上の数 | 発生時刻（練習の開始からの秒） |
| `actions[].action.type` | `"look"`・`"fire"`・`"ads"` のどれか | アクションの種類 |
| `actions[].action.yaw`・`actions[].action.pitch` | 数 | `look` のときだけ。照準の角度の変化（度）。ヨーは右が正、ピッチは上が正 |
| `actions[].action.pressed` | 真偽値 | `fire`・`ads` のときだけ。押した（真）・離した（偽） |

### 照準の軌道

- 入力の記録と開始時の照準（ヨー・ピッチ）から、照準の軌道を取り出せる。リザルトの軌道の重ね描きはこれを使う。
- 軌道の点は、時刻 0 の開始時の照準から始まり、固定ステップ（[architecture.md](architecture.md)）の終わりごとに 1 つずつ、
  そのステップまでの `look` を反映した利用者の照準を持つ。`look` の消費とピッチの範囲・ヨーの正規化はシミュレーションと同じ規則で行う。
- 軌道は、記録の最後のアクションを消費するステップの終わりの点まで続く。アクションが 1 つもない記録の軌道は、時刻 0 の点だけになる。

## 受け入れ条件

- **INP-1**: 入力方式が「自動」のとき、マウスで撃ったあとにパッドのボタンを押すと、入力方式の表示がパッドに変わる
- **INP-2**: 入力方式を「マウス」に固定しているとき、パッドを操作しても照準と射撃は反応しない
- **INP-3**: マウスで記録した自己ベストは、入力方式をパッドにしたときのリザルトと自己ベストに表示されない（逆も同じ）
- **INP-4**: `randomness` が 0 でない武器で練習した入力の記録を、同じ武器・マップで再生したとき、弾痕の位置と採点結果が元の練習と一致する
- **INP-5**: `randomness` が 0 でない武器で、同じ入力の記録の種だけを変えて再生したとき、弾痕の位置が元の練習と一致しない
- **INP-6**: `look`・`fire`・`ads` を含む入力を積んで練習したとき、記録の `actions` が積んだアクションと時刻を積んだ順にすべて含み、記録の `seed` がその練習の乱数の種になっている
- **INP-7**: 開始時の照準をヨー 0 度・ピッチ 0 度とし、時刻付きの `look` の列（0.1 秒にヨー +10 度、0.2 秒にピッチ -5 度）の記録から照準の軌道を取り出したとき、最初の点は時刻 0・ヨー 0 度・ピッチ 0 度、時刻 0.15 秒の前後の点はヨー 10 度・ピッチ 0 度、最後の点はヨー 10 度・ピッチ -5 度になり、点の時刻は固定ステップの間隔で増える
- **INP-8**: 練習とリザルトの画面に、入力の記録をファイルに保存する・コピーする・外部に送る操作がない
