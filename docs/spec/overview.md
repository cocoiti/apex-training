# 全体と制約

## 概要

ブラウザだけで Apex Legends の武器のリコイル（反動）制御を練習できる、非公式のファンツール。
マウスかパッドで撃ち、理想の補正軌道（ゴースト）と自分の補正のズレを可視化・採点する。
入力は「エイムアシストなしの素のリコイル制御」の練習に限り、ゲームの外で使える補正の出力は持たない。

## 用語

| 用語 | 意味 |
|------|------|
| リコイル | 1 発ごとに照準が跳ね上がる量（度）。武器ごとのパターンで決まる |
| 補正 | 利用者がリコイルを打ち消すために照準を動かすこと |
| ゴースト | 理想の補正軌道（リコイルのパターンを上下左右に反転したもの）を示す点 |
| ADS | 覗き込み（エイム）中の状態 |
| 入力方式 | マウス、またはパッド（コントローラー） |

## 振る舞い

### 対応環境

- PC のブラウザ（Chrome を主対象）でマウスとパッドを使える。
- タッチ操作だけの端末には対応しない。パッドを接続したタブレットなどでは、パッドで遊べる。

### 権利と表記

- EA / Respawn の画像・ロゴ・武器モデル・効果音を使わない。武器名はテキストだけで表示する。
- すべての画面のフッターに「非公式ファンツールであり、EA / Respawn とは無関係」と表示する。
- 効果音は自作したものか、Web Audio で合成したものだけを使う。

### 練習の範囲

- ブラウザ内での練習に限る。ゲームの起動中にマウスを自動で動かす機能や、補正値をアプリの外へ出力する機能
  （ファイル、外部デバイス、ほかのアプリとの連携）は持たない。
- パッドのエイムアシストは再現しない。パッドの設定画面に「エイムアシストなしの素のリコイル制御を練習する」と表示する。

### 公開

- サーバー処理のない静的サイトとして、リポジトリ名のサブパス（`/apex-training/`）で公開できる。
- 画面はハッシュ（`#/settings` など）で切り替える。どの画面の URL を直接開いても、その画面が表示される。
- 設定と自己ベストはブラウザの localStorage に保存する。localStorage が使えない環境（プライベートウィンドウ、
  保存の拒否など）でも、保存されないだけで練習はできる。

## 受け入れ条件

- **OVR-1**: どの画面を開いたときも、フッターに非公式ファンツールであり EA / Respawn と無関係である旨が表示される
- **OVR-2**: 配布物（ビルド結果）を調べたとき、EA / Respawn の画像・ロゴ・武器モデル・効果音が含まれていない
- **OVR-3**: サブパス `/apex-training/` に配置したビルド結果で `#/settings` を直接開いたとき、設定画面が表示され、武器データの読み込みが 404 にならない
- **OVR-4**: localStorage への書き込みが例外になる環境で練習を始めたとき、エラーで止まらずに練習でき、保存できないことが表示される
- **OVR-5**: アプリのどの画面にも、補正値や照準の動きをファイルや外部デバイスへ出力する操作がない
