# 武器とリコイル

## 概要

武器ごとのリコイルのパターンを JSON のデータとして持ち、時間で発射を判定してリコイルを照準に加える。
弾の向きのレイとマップの箱との交差で弾痕の位置を求め、中心からの角度のズレとして記録する。
公式の数値はないため、自分で撮影した射撃訓練場の動画から計測した数値の武器（L-STAR と C.A.R. SMG）だけを利用者に見せる。
仮の数値の武器データ（R-301 など 5 つ）は計測したデータに差し替えられる形で残すが、武器の一覧に入れず、どの画面の武器の選択肢にも出さない。
発射・リコイル・当たり判定はシミュレーション（`src/sim/`）の中で完結し、ブラウザなしで動かせる。

## 用語

| 用語 | 意味 |
|------|------|
| 武器データ | `src/data/weapons/` の JSON 1 つ分の、項目の確認を通った武器のデータ |
| 計測した武器データ | `measured` が `true` の武器データ。自分で撮影した動画から計測した数値で、計測の記録がある |
| 仮データの武器 | `measured` が `false` の武器データ。形だけそれらしい仮の数値で、利用者に見せない |
| 武器の一覧 | 読み込めた武器データのうち、計測した武器データだけの集まり。トップ画面・履歴の画面など、武器を選ぶ所の選択肢はすべてこの一覧から作る |
| 発射間隔 | 1 発ごとの時間。60000 ÷ `rpm` ミリ秒 |
| リコイルの累積 | 撃った弾の `pattern` を足し合わせた、照準に加わるオフセット（ヨー・ピッチ、度） |
| 戻りの時間 | 撃ち終わりからリコイルの累積が 0 に戻るまでの時間。0.5 秒 |
| 理想の補正軌道 | i 発目で照準を合わせるべき位置。1〜i 発目の `pattern` の合計を上下左右に反転したもの |
| 角度のズレ | 弾痕の位置を目の位置から見た向きと、中心（マップの開始時の照準）との差（水平・垂直、度） |

## 振る舞い

### 武器データ

- 武器は `src/data/weapons/` の JSON ファイル 1 つにつき 1 つ。`measured` が `true` のファイルを足すと、コードを変えずに武器の一覧に出る。
- JSON はビルドの配布物に含め、ビルド時のベースパス基準の URL で取得する（マップの JSON と同じ扱い）。
  ファイルの取得はシミュレーションの外で行い、中身の確認はシミュレーションの中で行う。
- 項目（すべて必須）:

  | 項目 | 型 | 内容 |
  |------|----|------|
  | `id` | 文字列 | 武器の ID |
  | `name` | 文字列 | 表示名（テキスト） |
  | `category` | 文字列 | 武器の種類（AR、SMG、LMG など。トップ画面の分類に使う） |
  | `version` | 文字列 | データが対象とするシーズン（例: `S31-Cipher`） |
  | `source` | 文字列 | 数値の計測元 |
  | `rpm` | 0 より大きい数 | 1 分あたりの発射数 |
  | `magSize` | 1 以上の整数 | 装弾数 |
  | `pattern` | `{ dx, dy }` の配列 | `pattern[i]` は i+1 発目で照準が跳ね上がる量（度）。右が +dx、上が +dy。要素数は `magSize` 以上で、超えた分は使わない |
  | `randomness` | 0 以上の数 | 各発に加わる ±ブレ（度）。0 なら毎回同じパターン |
  | `measured` | 真偽値 | 計測した値なら `true`、仮データなら `false` |

- 必須の項目がない、型や範囲が違う、`pattern` の要素数が `magSize` より少ない、のどれかに当たる JSON は武器の一覧から外し、
  ファイル名と誤りの項目を開発者向け（ブラウザのコンソール）に出力する。ほかの武器は一覧に残る。
- `measured` が `false` の武器データは誤りではなく、項目の確認を通っても武器の一覧に入れない。開発者向けの誤りとしても出力しない。
- `measured` が `true` の武器データには、同じ `id` の計測の記録（`docs/measurements/<id>.json`）がリポジトリにある。
- トップ画面の武器の選択肢は武器の一覧から作り、`category` ごとに分けて並べる（[screens.md](screens.md)）。
  履歴の画面の武器の選択肢も武器の一覧から作る。仮データの武器はどの選択肢にも出ない。

### MVP の武器

- 武器の一覧に出る（選択肢に出る）のは、計測した武器データの L-STAR と C.A.R. SMG の 2 つ。
- R-301、R-99、フラットライン、ボルト、スピットファイアの 5 つは仮データの武器で、JSON を `src/data/weapons/` に残す。
  形だけそれらしい仮の数値で、`measured` を `false` にし、`source` に仮データであることを書く。
  計測したときは、同じファイルの数値・`source`・`version` を計測した値に差し替え、`measured` を `true` にし、計測の記録を足すと、
  コードを変えずに武器の一覧に出る。
- L-STAR と C.A.R. SMG は計測した武器データ（下記）で、`measured` が `true`。`source` に「自分で撮影した射撃訓練場の動画からの計測」であること、
  撮影日、撮影の条件（計測時のアタッチメントを含む）を書き、`version` に撮影したシーズンを書く。
- C.A.R. SMG は `category` が `SMG`。`magSize` は計測時のアタッチメント（紫の拡張マガジン込み）での装弾数で、動画の装弾数の表示から取る。
- L-STAR は他の武器と同じ項目だけで表す。`magSize` は「過熱せずに撃ち続けられる発数」で、過熱するまで撃ち続けた 1 回の射撃の発数を計測した値。
  過熱（撃てなくなる時間など）は扱わない。撃ち切ったあとの振る舞いは他の武器と同じ。

### 計測した武器データ

- 計測は全弾のリコイルを見るため、その武器に付けられるアタッチメントをすべて紫（レベル 3）にして撮る。
  計測した武器データは、そのアタッチメントを付け、アイアンサイトで ADS し、射撃中に照準を動かさずに撃ったときの跳ねを表す。
  アタッチメントによる反動の変化は扱わず、アプリでは武器データの値をそのまま使う。
- 武器ごとの計測時のアタッチメントは、武器データの `source` と計測の記録の両方に書く。

  | 武器 | 計測時のアタッチメント |
  |------|----------------------|
  | L-STAR | すべて紫（レベル 3） |
  | C.A.R. SMG | すべて紫（レベル 3。拡張マガジンを含む） |

- `pattern[i]` は複数回の射撃で計測した i+1 発目の跳ねの平均、`randomness` はその射撃ごとのばらつきから求めた値。
  ほかの射撃から大きく外れた射撃（照準がずれたなど）は平均から外してよく、外した射撃とその理由を計測の記録に書く。
  外した射撃は `pattern` と `randomness` の計算にも許容差の計算にも使わない。
- 計測の換算（画面の動きから角度への換算、FOV・壁までの距離・射撃中の操作の前提）は武器によらず同じ方法で行い、
  撮影者に確かめられなかった条件は仮定として計測の記録に書く。
- 計測の記録（射撃ごとの各発の角度、撮影の条件と計測時のアタッチメント、平均から外した射撃と理由、許容差）は、
  武器ごとに数値だけをリポジトリの中の配布物に入らない場所に残す。
  計測に使った動画・切り出したフレーム・ゲーム画面の画像はリポジトリにも配布物にも入れない。

### 発射

- `fire` を押し始めたステップで 1 発目を撃ち、`fire` が続いている間は発射間隔ごとに 1 発撃つ。
  発射の時刻は経過時間（固定ステップの時刻）で判定し、表示のフレームレートに影響されない。
  ステップの刻みとの端数は次の発に持ち越し、発射間隔がステップの倍数でなくても 1 秒あたりの発数がずれない。
- 装弾数を撃ち切ると、`fire` を押し続けていても止まる。残弾が 0 のときに `fire` を押し直すと、装弾数に戻ってまた撃てる
  （リロードの時間は扱わない）。残弾があるうちに離して押し直したときは、残弾から続けて撃つ。
- 押し直したときの 1 発目は、前の発から発射間隔がたっていなくても押し始めたステップで撃つ。

### リコイル

- i 発目を撃つと、`pattern[i-1]` をリコイルの累積に足す。弾の向き = 利用者の照準（入力の累積）+ リコイルの累積 + その発のブレ。
  完全に補正すれば全弾が中心に集まる。
- ブレは、`randomness` が r のとき、水平・垂直それぞれに -r 以上 r 以下の値を種付きの乱数から取ってその発だけに加える。
  ブレはリコイルの累積に残らない。
- 撃ち終わり（`fire` を離す、または撃ち切る）から、リコイルの累積は戻りの時間（0.5 秒）をかけて一定の速さで 0 に戻る。
- 戻りきったあとに撃ち始めると、パターンは 1 発目から始まる。戻りきる前に撃ち始めたときは、残っている累積に続けて加え、
  パターンは続きの発から使う。ただし残弾 0 から押し直して装弾数に戻ったときは、パターンは 1 発目から始まる（累積は残る）。

### 当たり判定と弾痕

- 弾の向きのレイを目の位置から飛ばし、マップの箱（壁と的）のうち最も近い交点を弾痕の位置とする。
- 弾痕ごとに、発の番号、位置（メートル）、角度のズレ（水平・垂直、度。右と上が正）を記録する。
  どの箱にも当たらない弾は、位置なしの外れとして記録する。

### 理想の補正軌道

- 武器データから、i 発目の理想の補正軌道（1〜i 発目の `pattern` の合計の反転、ヨー・ピッチ、度）を求められる。
  同じ武器データなら常に同じ結果になり、乱数や入力に依存しない。
- ゴースト追従のゴースト、リザルトの理想の軌道の重ね描き、パッドのガイドは、この軌道を使う。

## 受け入れ条件

- **WPN-1**: `src/data/weapons/` に `measured` が `true` の新しい武器の JSON を 1 つ足してビルドしたとき、コードを変えずに武器の一覧に出る
- **WPN-2**: 必須の項目（例: `rpm`）が欠けた武器の JSON があるとき、その武器は武器の一覧に出ず、ファイル名と欠けた項目が開発者向けに出力され、ほかの武器は一覧に出る
- **WPN-3**: トップ画面を開いたとき、武器の選択肢に L-STAR と C.A.R. SMG の 2 つだけが出て、R-301・R-99・フラットライン・ボルト・スピットファイアは出ない
- **WPN-4**: rpm 600・装弾数 30 の武器で `fire` を 1 秒押し続けたとき、60Hz と 144Hz の描画間隔のどちらでも 10 発撃たれる
- **WPN-5**: 装弾数 28 の武器で `fire` を押し続けたとき、28 発で射撃が止まり、`fire` を離して押し直すとまた撃てる
- **WPN-6**: `randomness` が 0 の武器で照準を動かさずに撃ったとき、i 発目の弾は 1〜i 発目の `pattern` の合計の位置に当たる
- **WPN-7**: `randomness` が 0 の武器で、各発の `pattern` と逆向きにちょうど同じ量だけ照準を動かしたとき、全弾が中心に当たる
- **WPN-8**: `randomness` が 0 の武器で数発撃って `fire` を離し、戻りの時間（0.5 秒）より長く待ってから撃ったとき、1 発目は照準の位置 + `pattern[0]` に当たり、前の射撃のリコイルが残らない
- **WPN-9**: `randomness` が 0 より大きい武器で、同じ入力の記録と同じ種で 2 回撃ったとき弾痕の位置が一致し、各発の角度のズレと `randomness` 0 のときの位置との差が水平・垂直とも `randomness` 以下になる
- **WPN-10**: `range` のマップで照準を動かさず `randomness` 0・`pattern` がすべて `{ dx: 0, dy: 0 }` の武器で撃ったとき、弾痕の角度のズレが水平・垂直とも 0 度になる
- **WPN-11**: `pattern` が 1 発目 `{ dx: 1, dy: 2 }`、2 発目 `{ dx: -0.5, dy: 1 }` の武器で理想の補正軌道を求めたとき、1 発目は (-1, -2)、2 発目は (-0.5, -3) になる
- **WPN-12**: `pattern` の要素数が `magSize` より少ない武器の JSON があるとき、その武器は武器の一覧に出ず、ファイル名と `pattern` の誤りが開発者向けに出力される
- **WPN-13**: トップ画面を開いたとき、武器の一覧のすべての武器が `category` ごとに分かれて選択肢に出る
- **WPN-14**: 武器の一覧の計測した武器データ（L-STAR・C.A.R. SMG）をそれぞれ見たとき、`source` に自分で撮影した射撃訓練場の動画からの計測であることが書かれ、仮データである旨は書かれておらず、`version` に撮影したシーズンが書かれている
- **WPN-15**: 計測した武器データ（L-STAR・C.A.R. SMG）それぞれで `randomness` を 0 にして照準を動かさずに `magSize` 発撃ったとき、i 発目の弾は 1〜i 発目の `pattern` の合計の位置に当たり、`magSize` 発で射撃が止まる
- **WPN-16**: 計測した武器データ（L-STAR・C.A.R. SMG）それぞれについて、その計測の記録の平均に使った射撃のうち 1 本の i 発目の角度と、`pattern` の 1〜i 発目の合計との差を全発で比べたとき、水平・垂直とも計測の記録に書いた許容差に収まる
- **WPN-17**: リポジトリの追跡されたファイルを調べたとき、動画（mp4・mov・mkv・webm・avi）と画像（[overview.md](overview.md) の画像の拡張子）のファイルが見つからない
- **WPN-18**: 計測した武器データ（L-STAR・C.A.R. SMG）それぞれについて、武器データの `source` と計測の記録を見たとき、どちらにも計測時のアタッチメントが「すべて紫（レベル 3）」と書かれ、「アタッチメントなし」とは書かれていない
- **WPN-19**: 計測した武器データ（L-STAR・C.A.R. SMG）それぞれについて、計測の記録の射撃のうち平均から外したと書かれていない射撃だけで各発の角度の増分の平均を計算し直したとき、`pattern` の各発と水平・垂直とも 0.005 度以内で一致し、平均から外した射撃には理由が書かれている
- **WPN-20**: 武器の一覧の C.A.R. SMG の武器データを見たとき、`category` が `SMG` で、`magSize` が 30 である
- **WPN-21**: 項目の確認を通る、`measured` が `false` の武器の JSON があるとき、その武器はトップ画面と履歴の画面の武器の選択肢に出ず、開発者向けの誤りも出力されない。同じ JSON の `measured` を `true` にしてビルドすると、コードを変えずに両方の選択肢に出る
- **WPN-22**: `measured` が欠けた、または真偽値でない武器の JSON があるとき、その武器は武器の一覧に出ず、ファイル名と `measured` の誤りが開発者向けに出力される
- **WPN-23**: `src/data/weapons/` の JSON を調べたとき、`measured` が `true` のものには同じ `id` の計測の記録（`docs/measurements/<id>.json`）があり、`measured` が `false` のもの（R-301・R-99・フラットライン・ボルト・スピットファイア）は `source` に仮データであることが書かれている
