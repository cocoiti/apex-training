# 武器とリコイル

## 概要

武器ごとのリコイルのパターンを JSON のデータとして持ち、時間で発射を判定してリコイルを照準に加える。
公式の数値はないため、MVP の数値は仮のもので、後から計測したデータに差し替える。

## 振る舞い

### 武器データ

- 武器は `src/data/weapons/` の JSON ファイル 1 つにつき 1 つ。ファイルを足すと、コードを変えずに武器の選択肢に出る。
- 項目:

  | 項目 | 内容 |
  |------|------|
  | `id` | 武器の ID |
  | `name` | 表示名（テキスト） |
  | `category` | 武器の種類（AR、SMG、LMG など。トップ画面の分類に使う） |
  | `version` | データが対象とするシーズン（例: `S31-Cipher`） |
  | `source` | 数値の計測元 |
  | `rpm` | 1 分あたりの発射数 |
  | `magSize` | 装弾数 |
  | `pattern` | `pattern[i]` は i 発目で照準が跳ね上がる量 `{ dx, dy }`（度）。右が +dx、上が +dy |
  | `randomness` | 各発に加わる ±ブレ（度）。0 なら毎回同じパターン |

- 必須の項目が欠けた JSON は選択肢に出さず、どのファイルの何が足りないかを開発者向けに出力する。
- MVP の武器: R-301、R-99、フラットライン、ボルト、スピットファイア。形だけそれらしい仮の数値で、`source` に仮データであることを書く。

### 発射とリコイル

- `fire` が続いている間、発射間隔（60000 ÷ rpm ミリ秒）ごとに 1 発撃つ。発射は経過時間で判定し、
  表示のフレームレートに影響されない。
- 弾の向き = 利用者の照準（入力の累積）+ リコイルの累積。完全に補正すれば全弾が中心に集まる。
- 装弾数を撃ち切ると止まり、次に `fire` を押し直すと装弾数が戻る（リロードの時間は MVP では扱わない）。
- 撃ち終わり（`fire` を離す、または撃ち切る）から、リコイルの累積が一定時間で 0 に戻る。

## 受け入れ条件

- **WPN-1**: `src/data/weapons/` に新しい武器の JSON を 1 つ足してビルドしたとき、コードを変えずにトップ画面の武器の選択肢に出る
- **WPN-2**: 必須の項目が欠けた武器の JSON があるとき、その武器は選択肢に出ず、ほかの武器は選べる
- **WPN-3**: トップ画面で R-301・R-99・フラットライン・ボルト・スピットファイアを選べる
- **WPN-4**: rpm 600・装弾数 30 の武器で `fire` を 1 秒押し続けたとき、60Hz と 144Hz の表示のどちらでも 10 発撃たれる
- **WPN-5**: 装弾数 28 の武器で `fire` を押し続けたとき、28 発で射撃が止まる
- **WPN-6**: `randomness` が 0 の武器で照準を動かさずに撃ったとき、i 発目の弾は 1〜i 発目の `pattern` の合計の位置に当たる
- **WPN-7**: `randomness` が 0 の武器で、各発の `pattern` と逆向きにちょうど同じ量だけ照準を動かしたとき、全弾が中心に当たる
