# パッド入力

## 概要

パッドは「スティックの傾き = 視点の回転速度（度/秒）」で照準を動かす。Apex の詳細視点設定（ALC）に寄せた
パラメータを持つが、Apex 内部の式は非公開のため近似であり、UI に「ゲームと完全に一致するものではなく、
近い感覚で練習できる」と表示する。エイムアシストは再現しない（[overview.md](overview.md)）。

## 振る舞い

### 接続と配置

- ブラウザはパッドのボタンが押されるまでパッドを報告しない。パッドを接続してボタンを押すと検出される。
- ブラウザが報告するパッドの配置（Gamepad API の `mapping`）が `"standard"` のとき、標準配置として扱う。
  それ以外（空文字など）のときは標準配置として扱わない。
- 標準配置として扱えるパッドでは、右スティックが `look`、R2 / RT が `fire`、L2 / LT が `ads`。
  標準配置の番号では、右スティックが軸 2（左右）と軸 3（上下）、R2 / RT がボタン 7、L2 / LT がボタン 6。
- 標準配置では、A / ×（ボタン 0）と B / ○（ボタン 1）で練習の流れの画面の操作（やり直す・次へ・やめる・もう一度・武器変更）ができる
  （[screens.md](screens.md)「画面の操作」）。
- 標準配置では、十字キー（ボタン 12〜15）・左スティック（軸 0・1）・A / ×・B / ○ で、トップ・設定・履歴・キャリブレーション・
  ボタン割り当ての画面の項目の移動・値の変更・決定・戻るができる（[screens.md](screens.md)「パッドでの項目の移動と変更」）。
  プレイ画面では十字キーと左スティックは何の操作にもならない。
- A / ×・B / ○・十字キー・左スティックはアクション（`look`・`fire`・`ads`）にならず、入力の記録にも入らない。
  右スティック・R2 / RT・L2 / LT（と割り当てたボタン・軸）は画面の項目の操作に使わない。
- R2 / RT と L2 / LT は、アナログ値がしきい値（既定 0.5）以上の間を押している状態とする。R2 / RT を押している間が
  `fire`、L2 / LT を押している間が `ads`。ボタン割り当てで割り当てたボタンも、値がしきい値以上の間を押している状態とする。
- パッドの値はポーリングで読み取る（描画のたびに最新の値を読む）。入力に使うパッドが外れたら、`look` を止め、`fire` と `ads` を
  離した状態にする。

### 入力に使うパッド

- ブラウザが見つけたパッドのうち、次のどちらかに当たるものを「使えるパッド」とする。
  - 接続していて、標準配置として扱えるパッド。
  - 接続していて、標準配置として扱えないが、ボタン割り当てが保存されているパッド（割り当ては名前で照らす）。
- 入力に使うパッドは、使えるパッドのうち番号（Gamepad API の `index`）が最も小さいもの 1 つだけとする。
  ほかのパッドの入力は無視する。使えないパッドが小さい番号で先に見つかっていても、使えるパッドがあればそれを使う。
- 使えるパッドがないときは、パッドの入力はないものとして扱う（`look` を止め、`fire` と `ads` を離した状態にする）。
- 入力に使うパッドの状態は、次の 3 つのどれかとして表示する。パッドの名前は下の「パッドの名前」のとおりに表示する。

  | 状態 | 条件 | 表示 |
  |------|------|------|
  | 使用中 | 使えるパッドがある | 入力に使うパッドの名前 |
  | 見つからない | 接続しているパッドが 1 つもない | 「パッドが見つかりません。パッドのボタンを押してください」 |
  | 標準配置でない | 接続しているパッドはあるが、使えるパッドがない | 「標準配置でないパッドです（ボタン割り当てが必要）」と、番号が最も小さい接続しているパッドの名前 |

- 練習中の HUD には、入力方式の設定が「パッド」か「自動」のとき、入力方式の表示（[input.md](input.md)）の隣にこの状態を表示し、
  描画のたびに今の状態に更新する。入力方式の設定が「マウス」のときは表示しない。
- パッドの設定画面（設定画面のパッドの区分）と、キャリブレーション画面にも同じ状態を表示する。

### パッドの名前

- パッドの名前は Gamepad API の `id` とする。`id` が空文字のときは名前が分からないものとし、「パッド」と表示する。
- パッドの名前を表示するところ（入力に使うパッドの状態、パッドの一覧、ボタン割り当て画面、練習中のガイド、リザルトの入力推移のグラフの見出し）は、
  すべてこの決まりで名前を求める。
- 練習中の HUD だけは、名前の最初の「 (」より前の部分を最大 32 文字まで表示する（32 文字を超えるときは 31 文字と「…」）。
  ほかのところでは省略しない。

### パッドの一覧

- キャリブレーション画面に、ブラウザが見つけたパッドを番号の順に一覧で表示する。表示は描画のたびに更新する。
  外れたパッドも、ブラウザが一覧に残している間は表示する。

  | 列 | 内容 |
  |----|------|
  | 番号 | Gamepad API の `index` |
  | 名前 | パッドの名前（「パッドの名前」。省略しない） |
  | 配置 | `mapping` の値。空文字のときは「（空）」 |
  | 標準配置 | 標準配置として扱うか（「はい」/「いいえ」） |
  | 割り当て | 標準配置でないパッドで、ボタン割り当てが保存されているか（「済み」/「なし」）。標準配置のパッドでは「—」 |
  | 接続 | 接続しているか（「はい」/「いいえ」） |
  | 入力 | 入力に使っているパッドの行だけに「使用中」 |

- パッドが 1 つも見つかっていないときは、一覧の代わりに「パッドが見つかりません。パッドのボタンを押してください」と表示する。

### ボタン割り当て

- ボタン割り当て画面（`#/settings/pad/mapping`）では、標準配置として扱えないパッドに `fire`・`ads`・右スティックの左右・
  右スティックの上下を割り当てる。対象は、接続している標準配置でないパッドのうち番号が最も小さいもので、画面にその名前を表示する。
  対象がないときは「標準配置でないパッドがつながっていません」と表示する。
- 項目ごとに「割り当てる」を押してから操作すると、その操作で割り当てが決まる。
  - `fire`・`ads`: 押したあとに値がしきい値（0.5）以上になった最初のボタンの番号。
  - 右スティックの左右: 「右に倒してください」と案内し、絶対値が 0.5 以上になった最初の軸の番号。そのときの値が負なら向きを反転して扱う。
  - 右スティックの上下: 「上に倒してください」と案内し、絶対値が 0.5 以上になった最初の軸の番号。そのときの値が正なら向きを反転して扱う
    （反転しないときは標準配置と同じく、値が負の向きを上とする）。
- 割り当てた番号は項目ごとに表示する。4 つの項目がすべて割り当てられたとき、そのパッドの割り当てとして保存する。
  保存した割り当ては次に開いたときも残る。保存先は localStorage のキー `apex-training:pad-mapping` で、パッドの名前（`id`）ごとに持つ。
- 「割り当てを消す」を押すと、そのパッドの保存した割り当てを消す。
- 割り当てを保存したパッドは使えるパッドになり、割り当てた軸を `look`、割り当てたボタンを `fire`・`ads` として、標準配置のパッドと
  同じ規則（スティックの式・しきい値・ADS 中の速度）で読む。
- トップ画面か設定画面を開いている間に、標準配置として扱えず割り当てのないパッドだけがつながっていて、そのパッドのボタンが押されたときは、
  ボタン割り当て画面を開く。同じパッドについては、ページを開いている間に 1 回だけ開く。練習中は開かず、HUD の表示（「標準配置でない」）だけにする。
- 設定画面のパッドの区分には、ボタン割り当て画面へのリンクがある。

### スティックから視点の回転へ

- スティックの傾きを、デッドゾーン・外側しきい値・レスポンスカーブで 0〜1 の入力量にし、最大回転速度を掛けた
  速度（度/秒）で照準を回す。経過時間で積分するため、フレームレートが違っても回転量は同じになる。
- 入力量の求め方（デッドゾーン d、外側しきい値 o はどちらも 0〜1 の割合、レスポンスカーブ c）:
  1. 右スティックの 2 軸の値 (x, y) から傾きの大きさ m = √(x² + y²) を求める（1 を超えたら 1）。
  2. 正規化した傾き t = (m − d) ÷ (1 − o − d) を 0〜1 に収める。m が d 以下なら 0、1 − o 以上なら 1。
  3. 入力量 = t ^ (1 + c ÷ 8)。c が 0 のときはリニア（入力量 = t）。
  4. 回転の向きはスティックを倒した向き (x ÷ m, y ÷ m) のまま、大きさだけを入力量に置き換える。
- 回転速度は、ヨー速度 = 入力量 × 向きの左右成分 × 最大ヨー速度、ピッチ速度 = 入力量 × 向きの上下成分 × 最大ピッチ速度。
  ADS 中は ADS ヨー速度・ADS ピッチ速度を最大回転速度として使う。
- 向きは、スティックを右に倒すとヨーが増え（右を向く）、上に倒すとピッチが増える（上を向く）。上下の反転はしない。
- 各固定ステップでは、その時点で最新のスティックの値から回転速度を求め、固定ステップの長さ（秒）を掛けた角度（度）を
  `look` として出す。回転量は描画の間隔によらず、経過したステップの数だけで決まる。
- 入力量と回転速度の式は近似で、実機と見比べて定数を調整できるよう 1 か所にまとめる。
- 詳細設定（ALC 相当）の項目と既定値:

  | 項目 | 内容 | 範囲 | 既定値 |
  |------|------|------|--------|
  | デッドゾーン | 中心付近の無効範囲（%） | 0〜30 | 10 |
  | 外側しきい値 | 端の何 % を最大入力とするか | 0〜30 | 2 |
  | レスポンスカーブ | 傾き→速度の曲線の強さ。0 でリニア、0〜2 でほぼリニア、8 前後でクラシック | 0〜20 | 2 |
  | ヨー速度 / ピッチ速度 | 腰撃ちの最大回転速度（度/秒） | 0〜500 | 300 / 260 |
  | ADS ヨー速度 / ADS ピッチ速度 | ADS 中の最大回転速度（度/秒） | 0〜500 | 90 / 78 |

- 簡易設定（ALC OFF 相当）では、視点感度（1〜6）・ADS 感度（1〜6）・カーブ（クラシック / リニア）だけを選ぶ。
  選んだ値は次の対応表で詳細設定の項目の値に置き換えて使う。既定は詳細設定で、簡易設定を選んだときの初期値は
  視点感度 4・ADS 感度 4・カーブ クラシック（腰撃ちと ADS の速度が詳細設定の既定値と同じになる）。

  視点感度 → 腰撃ちの最大回転速度:

  | 視点感度 | 1 | 2 | 3 | 4 | 5 | 6 |
  |---------|---|---|---|---|---|---|
  | ヨー速度（度/秒） | 120 | 180 | 240 | 300 | 360 | 420 |
  | ピッチ速度（度/秒） | 104 | 156 | 208 | 260 | 312 | 364 |

  ADS 感度 → ADS 中の最大回転速度:

  | ADS 感度 | 1 | 2 | 3 | 4 | 5 | 6 |
  |---------|---|---|---|---|---|---|
  | ADS ヨー速度（度/秒） | 45 | 60 | 75 | 90 | 105 | 120 |
  | ADS ピッチ速度（度/秒） | 39 | 52 | 65 | 78 | 91 | 104 |

  カーブ → 曲線とデッドゾーン:

  | カーブ | レスポンスカーブ | デッドゾーン（%） | 外側しきい値（%） |
  |-------|----------------|-----------------|-----------------|
  | クラシック | 8 | 10 | 2 |
  | リニア | 0 | 10 | 2 |

### パッドの設定画面

- 設定画面のパッドの区分には、次を表示する。
  - 「エイムアシストは再現しません。エイムアシストなしの素のリコイル制御を練習します」
  - 「ゲームと完全に一致するものではなく、近い感覚で練習できます」
  - 入力に使うパッドの状態（「入力に使うパッド」）
  - 簡易設定 / 詳細設定の切替と、それぞれの項目
  - 振動（ON/OFF）
  - ボタン割り当て画面（`#/settings/pad/mapping`）とキャリブレーション画面（`#/settings/pad`）へのリンク
- 詳細設定の項目の入力欄は、範囲の外の数を近いほうの端の値にし、小数を四捨五入する（すべて整数の項目）。数として読めない入力や
  空の入力は保存しない（[screens.md](screens.md) の入力の規則と同じ）。
- 簡易設定を選んでいる間は、詳細設定の欄に対応表で置き換えた値を表示し、欄は変更できない。詳細設定に戻すと、
  最後に詳細設定で使っていた値に戻る（簡易設定の値と詳細設定の値は別々に保存する）。
- 練習のスティックの換算には、「開始」を押した時点のパッドの設定（簡易設定のときは対応表で置き換えた値）を使う。

### キャリブレーション

- キャリブレーション画面（`#/settings/pad`）には、パッドの一覧（「パッドの一覧」）と、表示の対象のパッドの値を表示する。
  対象は入力に使うパッドで、ないときは番号が最も小さい接続しているパッド。
- 対象のパッドのすべての軸の生の値（−1〜1、小数第 2 位まで）と、すべてのボタンの値（0〜1、小数第 2 位まで）を、描画のたびに更新して表示する。
- 右スティック（入力に使うパッドの look の 2 軸。標準配置でなく割り当てのないパッドでは軸 2 と軸 3）の位置を、半径を傾き 1 とする円の中の点で表示し、
  今のデッドゾーンの範囲を半径「デッドゾーン ÷ 100」の円、外側しきい値の境目を半径「1 − 外側しきい値 ÷ 100」の円として重ねる。
- キャリブレーション画面にはデッドゾーンの入力欄があり、パッドの設定のデッドゾーンと同じ値を変える。変えると重ねた円の大きさがすぐに変わる。
  簡易設定のときは欄を変更できない（簡易設定のカーブの値を表示する）。
- 設定画面へ戻るリンクがある。

### 振動

- 入力に使うパッドで弾が 1 発出るたびに、パッドを 1 回振動させる。振動の要求は Gamepad API の
  `vibrationActuator.playEffect("dual-rumble", …)` で、長さ 60 ミリ秒・強い側の強さ 0.2・弱い側の強さ 0.5（0〜1）とする。
- 振動の設定が OFF のときは、振動の要求を出さない。既定は ON。
- 今の入力方式がマウスのときと、入力の記録の再生では振動しない。
- パッドかブラウザが振動に対応しない（`vibrationActuator` がない、`playEffect` がない、要求が失敗する）ときは何もしない。
  エラーにせず、練習はそのまま続く。
- 入力に使うパッドが振動に対応しないときは、パッドの設定画面の振動の項目の隣に「このパッドまたはブラウザは振動に対応していません」と表示する。
  プレイ画面には案内を出さない。

### パッド向けのガイド

#### 理想の補正速度

- 理想の補正速度は、理想の補正軌道（[weapons.md](weapons.md)）を照準でなぞるための回転速度（ヨー・ピッチ、度/秒）。
  `fire` を押していて、次に撃つ弾（[modes.md](modes.md) の反復練習と同じ数え方）が k 発目（k ≥ 2）のとき、
  （k 発目の理想の補正軌道 − (k − 1) 発目の理想の補正軌道）÷ 発射間隔（60 ÷ `rpm` 秒）。
- 次のときは 0（スティックを倒さない）: `fire` を押していない、次に撃つ弾が 1 発目（まだ撃っていない、またはリコイルの累積が戻りきった）、
  撃ち切った。

#### カーブの逆

- 回転速度 (vy, vp)（度/秒）から、その速度を出すスティックの位置を「スティックから視点の回転へ」の式の逆で求める。
  使う最大回転速度・デッドゾーン d・外側しきい値 o・レスポンスカーブ c は、その練習に当てたパッドの設定（簡易設定のときは対応表で置き換えた値）。
  ADS 中は ADS ヨー速度・ADS ピッチ速度を使う。
  1. 速度を最大回転速度で割った (u, w) = (vy ÷ 最大ヨー速度, vp ÷ 最大ピッチ速度) から、入力量 q = √(u² + w²) を求める（1 を超えたら 1）。
  2. q が 0 ならスティックの位置は中心 (0, 0)。
  3. 正規化した傾き t = q ^ (1 ÷ (1 + c ÷ 8))、傾きの大きさ m = d + t × (1 − o − d)。
  4. スティックの位置は、向き (u ÷ √(u² + w²), w ÷ √(u² + w²)) に大きさ m を掛けたもの（右と上が正）。
- 求めたスティックの位置を「スティックから視点の回転へ」の式に通すと、q が 1 以下なら元の回転速度に戻る。
  q が 1 を超える（最大回転速度より速い）ときは、同じ向きに倒し切った位置になる。
- 最大回転速度が 0 の軸に 0 でない速度を求めたときは、その軸の成分を 0 として扱う。

#### 練習中のガイド

- 反復練習（[modes.md](modes.md)）で、今の入力方式（[input.md](input.md)「入力方式の切替」）がパッドのあいだ、
  設定のゴースト表示（3D の中のゴースト）の ON/OFF によらず、プレイ画面にスティック型のガイドを表示する。センター維持では表示しない。
- ガイドは、右スティックの可動範囲を表す円と、その中に次の 2 つの点を描く。円の中心がスティックの中心、円の縁が倒し切った位置。
  - 理想の位置: 今の理想の補正速度をカーブの逆で直したスティックの位置。描画のたびに置き直す。
  - 今の位置: 今の右スティックの値（デッドゾーンをかける前）の位置。
- ガイドの近くに、入力に使っているパッドの名前（「パッドの名前」）を表示する。
- 今の入力方式がマウスのとき、撃ち切ったときと練習が終わったとき（リザルト画面に移るとき）は、ガイドを表示しない。
  練習中に入力方式がマウスに変わったら、すぐにガイドを消す。
- ガイドは表示だけで、シミュレーションの状態（弾痕・採点）と入力の記録を変えない。

#### リザルトの入力推移のグラフ

- 練習の入力方式（[input.md](input.md)）がパッドのとき（反復練習・センター維持）、リザルト画面に
  右スティックの入力推移のグラフを表示する。練習の入力方式がマウスのときは表示しない。
- グラフは横軸が練習の開始からの時刻（秒）、縦軸がスティックの位置（−100〜100%、右と上が正）で、左右の成分と上下の成分を
  別のグラフにし、それぞれに自分の推移と理想の推移を重ねる。
  - 自分の推移: 入力の記録から、固定ステップごとにそのステップの `look` の角度 ÷ ステップの長さで回転速度を求め、
    カーブの逆でスティックの位置に直した値。そのステップの ADS の状態は記録の `ads` から決める。
  - 理想の推移: 入力の記録を再生したときの各固定ステップの `fire` の状態と次に撃つ弾から理想の補正速度を求め、
    カーブの逆でスティックの位置に直した値。
  - どちらも、照準の軌道（[input.md](input.md)）と同じく、記録の最後のアクションを消費するステップまでの点を持つ。
- グラフの見出しに、練習の入力方式を決めたとき（1 発目を撃ったとき）に入力に使っていたパッドの名前（「パッドの名前」）を表示する。

## 受け入れ条件

- **PAD-1**: DualSense と Xbox のパッドをそれぞれ接続したとき、右スティックで照準が動き、R2 / RT で射撃、L2 / LT で ADS ができる
- **PAD-2**: パッドが 1 つも見つかっていない（接続してまだボタンを押していない）とき、パッドの設定画面と、入力方式の設定が「自動」の練習中の HUD に「パッドが見つかりません。パッドのボタンを押してください」と表示される
- **PAD-3**: 標準配置として扱えないパッド（`mapping` が空文字）だけを接続し、トップ画面でそのパッドのボタンを押したとき、ボタン割り当て画面が表示され、4 つの項目を割り当てたあとに練習を始めると、`fire` に割り当てたボタンで射撃でき、割り当てた軸で照準が動く
- **PAD-4**: デッドゾーン 10% で、スティックの傾きが 8% のまま 1 秒保ったとき、照準は動かない
- **PAD-5**: スティックを同じ傾き（50%）で 1 秒倒し続けたとき、60Hz と 144Hz の描画間隔で照準の回転量が同じになる
- **PAD-6**: デッドゾーン 0%・外側しきい値 0%・レスポンスカーブ 0（リニア）・ヨー速度 300 で、右スティックを右に倒し切って 1 秒保ったとき、ヨーが 300 度変わる
- **PAD-7**: R2 の値が 0.4 のときは `fire` が出ず、0.6 のときは `fire` が出る（しきい値 0.5）
- **PAD-8**: 振動を OFF にしてパッドで射撃したとき、振動の要求が出ない。ON のときは、弾が 1 発出るたびに長さ 60 ミリ秒・強い側 0.2・弱い側 0.5 の `dual-rumble` の要求が 1 回出る
- **PAD-9**: パッドの設定画面に、エイムアシストを再現しないことと、ゲームと完全一致ではないことが表示される
- **PAD-10**: 簡易設定で視点感度・ADS 感度・カーブを選んだとき、詳細設定の値が対応表のとおりになる（例: 視点感度 2・ADS 感度 5・リニアでは、ヨー 180・ピッチ 156・ADS ヨー 105・ADS ピッチ 91・レスポンスカーブ 0・デッドゾーン 10%・外側しきい値 2%）
- **PAD-11**: `mapping` が `"standard"` のパッドは標準配置として扱われ、`mapping` が空文字のパッドは標準配置として扱われない
- **PAD-12**: デッドゾーン 0%・外側しきい値 0%・レスポンスカーブ 0・ピッチ速度 260 で、右スティックを上に倒し切って 1 秒保ったとき、出た `look` のピッチの変化の合計が +260 度になる（照準のピッチは上限の 89 度で止まる）
- **PAD-13**: デッドゾーン 0%・外側しきい値 0%・レスポンスカーブ 0・ADS ヨー速度 90 で、L2 を押したまま右スティックを右に倒し切って 1 秒保ったとき、ヨーが 90 度変わる
- **PAD-14**: デッドゾーン 10%・外側しきい値 2%・レスポンスカーブ 8・ヨー速度 300 で、右スティックを右に 54% 倒して 1 秒保ったとき、ヨーが 75 度変わる
- **PAD-15**: デッドゾーン 10%・外側しきい値 2%・レスポンスカーブ 0（リニア）と 8（クラシック）のそれぞれで、最大回転速度より遅い回転速度をカーブの逆でスティックの位置に直し、その位置を「スティックから視点の回転へ」の式に通したとき、元の回転速度に戻る（ヨー・ピッチの両方、ADS 中も）
- **PAD-16**: デッドゾーン 10%・外側しきい値 2%・レスポンスカーブ 8・ヨー速度 300 で、右向きのヨー速度 75 度/秒をカーブの逆で直したとき、スティックの位置は右に 54%（上下は 0）になる。回転速度 0 を直したときは中心になる
- **PAD-17**: 反復練習で、入力方式がパッドのとき（ゴースト表示が ON でも OFF でも）、プレイ画面にスティック型のガイドと入力に使っているパッドの名前が表示され、`fire` を押し続けて 2 発目以降を撃つあいだ、ガイドの理想の位置がその武器の理想の補正速度をカーブの逆で直した位置になる
- **PAD-18**: 入力方式がマウスのとき、センター維持のときは、プレイ画面にスティック型のガイドが表示されない。入力方式が「自動」でパッドで練習中にマウスを操作したとき、ガイドが消える
- **PAD-19**: パッドで反復練習かセンター維持を練習して終えたとき、リザルト画面に右スティックの入力推移のグラフ（左右と上下、それぞれ自分と理想の推移）と、使ったパッドの名前が表示される。マウスで練習して終えたときは表示されない
- **PAD-20**: パッドの右スティックを、リニアの設定で理想の補正速度をカーブの逆で直した位置に各ステップで倒して記録した入力の記録から入力推移のグラフを作ったとき、自分の推移と理想の推移が一致する
- **PAD-21**: キャリブレーション画面で、右スティックの軸の値を 0 から 0.6 に変えると軸の生の値の表示が 0.60 に変わり、R2 の値を 0.3 にするとボタンの値の表示が 0.30 に変わる
- **PAD-22**: キャリブレーション画面で、デッドゾーンを 10 から 20 に変えると、重ねたデッドゾーンの円の半径が 2 倍になる
- **PAD-23**: 振動に対応しないパッド（`vibrationActuator` がない）で射撃したとき、エラーにならずに練習が続き、撃ち切るとリザルト画面に移る。パッドの設定画面に「このパッドまたはブラウザは振動に対応していません」と表示される
- **PAD-24**: 標準配置でないパッド（`mapping` が空文字、割り当てなし）だけがつながっているとき、練習中の HUD とパッドの設定画面に「標準配置でないパッドです（ボタン割り当てが必要）」とそのパッドの名前が表示され、そのパッドを操作しても照準と射撃は反応しない
- **PAD-25**: 番号 0 に標準配置でないパッド（割り当てなし）、番号 1 に標準配置のパッドがつながっているとき、番号 1 のパッドで照準と射撃ができ、HUD に番号 1 のパッドの名前が表示され、キャリブレーション画面の一覧で番号 1 の行だけに「使用中」が表示される
- **PAD-26**: キャリブレーション画面の一覧に、見つかったパッドごとに番号・名前（`id`）・配置（`mapping`、空文字は「（空）」）・標準配置として扱うか・割り当ての有無・接続しているかが表示される
- **PAD-27**: 標準配置でないパッドにボタン割り当てを保存して再読み込みしたとき、割り当てが残っていて、同じ名前のパッドがそのまま使えるパッドになる。「割り当てを消す」を押すと標準配置でないパッドの扱いに戻る
- **PAD-28**: 設定画面でパッドの詳細設定のヨー速度を 150 にしてから練習を始め、デッドゾーン 0%・外側しきい値 0%・レスポンスカーブ 0 で右スティックを右に倒し切って 1 秒保ったとき、ヨーが 150 度変わる
- **PAD-29**: 簡易設定を選んでいる間は詳細設定の欄が対応表の値を表示して変更できず、詳細設定に戻すと簡易設定を選ぶ前の詳細設定の値が表示される
- **PAD-30**: 入力方式の設定が「マウス」のとき、練習中の HUD にパッドの状態が表示されない
- **PAD-31**: `id` が空文字のパッドを入力に使っているとき、練習中の HUD・キャリブレーション画面の一覧・ガイド・リザルトの入力推移のグラフの見出しに、名前として「パッド」が表示される。`id` が `DualSense Wireless Controller (STANDARD GAMEPAD Vendor: 054c Product: 0ce6)` のときは、HUD に `DualSense Wireless Controller`、ガイドとグラフの見出しと一覧には `id` が省略されずに表示される
- **PAD-32**: 標準配置のパッドで練習中に十字キーの上下左右を押し、左スティックを倒し切ったとき、`look`・`fire`・`ads` が出ず、照準が動かず、その練習の入力の記録にそれらの操作が入らない
- **PAD-33**: トップ画面と設定画面で、右スティックを倒し切ったり R2 / RT・L2 / LT を押し切ったりしても、フォーカスは移らず、項目の値は変わらない
