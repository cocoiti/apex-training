# 採点とリザルト

## 概要

各弾の中心からの角度のズレを記録し、まとまり・崩れる位置・ズレの方向を指標にして表示する。
練習が終わるとリザルト画面に指標と弾痕・照準の軌道を表示し、武器・モード・入力方式ごとの自己ベストを保存する。

## 用語

| 用語 | 意味 |
|------|------|
| 水平のズレ・垂直のズレ | 弾痕の角度のズレ（[weapons.md](weapons.md)）の水平成分 h と垂直成分 v（度）。右と上が正 |
| ズレの大きさ | 中心からの角度の距離 √(h² + v²)（度） |
| 的の半径 | 命中とみなす、中心からの角度の距離の上限（度） |
| 偏りのしきい値 | コメントを出すかどうかを分ける値。0.5 度 |

## 振る舞い

### 採点の入力

- 採点は、撃った順の弾ごとの水平のズレ・垂直のズレ（度）と、的の半径（度）だけから決まる。同じ入力なら同じ結果になる。
- 採点は武器・モード・入力方式によらず同じ計算で行う。

### 指標

n 発の i 発目の水平のズレを hᵢ、垂直のズレを vᵢ、ズレの大きさを dᵢ とする。

| 指標 | 定義 |
|------|------|
| 平均ズレ | dᵢ の平均（度） |
| グルーピング半径 | 弾痕の 95% が入る、弾痕の重心を中心とした円の半径（度） |
| 命中率 | dᵢ が的の半径以下の弾の割合（%） |
| 区間ごとのズレ | 撃った弾を前半・中盤・後半の 3 つに分けた、それぞれの平均ズレ（度） |
| 横ブレと縦ブレ | 横ブレ（\|hᵢ\| の平均、度）と縦ブレ（\|vᵢ\| の平均、度）と、その比（横ブレ ÷ 縦ブレ） |

- グルーピング半径は次の手順で求める。
  1. 重心を（hᵢ の平均, vᵢ の平均）とし、各弾の重心からの距離を求める。
  2. 距離を小さい順に並べ、⌈0.95 × n⌉ 番目（1 から数える）の距離をグルーピング半径とする。
- 命中の判定は的の半径ちょうどを含む（dᵢ = 的の半径なら命中）。
- 区間は撃った順に分ける。k 番目の区間（k = 0 が前半、1 が中盤、2 が後半）には、
  発の番号（0 から数える）が ⌊k × n ÷ 3⌋ 以上 ⌊(k + 1) × n ÷ 3⌋ 未満の弾が入る。
  n が 3 で割り切れないときは、余りの弾が後ろの区間から 1 発ずつ入る（28 発なら 9・9・10 発、29 発なら 9・10・10 発）。
- 弾が 1 発も入らない区間の平均ズレは「なし」とする（n が 3 未満のとき）。
- 縦ブレが 0 のとき、横ブレと縦ブレの比は「なし」とする。
- 1 発も撃たなかったときは、すべての指標を「なし」とし、コメントも出さない。

### コメント

- 垂直のズレの平均（vᵢ の平均、符号つき）と横ブレから、次の表のコメントを選ぶ。縦と横で 1 つずつ、合わせて最大 2 つを、
  縦・横の順に表示する。

| 条件 | コメント |
|------|---------|
| 垂直のズレの平均が −0.5 度以下（弾が中心より下に寄っている） | 下げすぎ |
| 垂直のズレの平均が +0.5 度以上（弾が中心より上に寄っている） | 下げ不足 |
| 横ブレが 0.5 度以上 | 横の補正不足 |
| 上のどれにも当たらない | よくまとまっている |

- しきい値ちょうど（−0.5 度、+0.5 度、0.5 度）は条件に当たるものとする。

### リザルト画面

- 練習が終わると、その練習の武器・モード・入力方式・弾痕の記録・入力の記録（[input.md](input.md)）と採点結果を受け取って表示する。
- 採点するモード（ゴースト追従・センター維持）では、次を表示する。
  - 指標（平均ズレ・グルーピング半径・命中率・区間ごとのズレ・横ブレと縦ブレと比）とコメント。「なし」の指標は「なし」と表示する。
  - 弾痕の散布図。各弾の水平のズレ・垂直のズレ（度）を、中心を原点に右と上を正として点で描き、的の半径の円を重ねる。
  - 自分の照準の軌道と理想の軌道（[weapons.md](weapons.md) の理想の補正軌道）の重ね描き。自分の照準の軌道は入力の記録から求めた、
    各弾の発射時の照準（開始時の照準からのヨー・ピッチ、度）を撃った順に結んだ線で、理想の軌道は 1 発目から撃った弾数までの理想の補正軌道を結んだ線。
  - 自己ベスト（下の「自己ベスト」）。
- パターン観察では採点しない。指標・コメント・自己ベストを表示せず、弾痕と、補正しなかった場合のパターン
  （1〜i 発目の `pattern` の合計を i 発目の位置として、撃った弾数まで結んだもの）を同じ座標に重ねて表示する。
- 1 発も撃たずに終わることはない（[modes.md](modes.md)）が、弾が 1 発もない結果を渡されたときは、指標を「なし」と表示し、散布図と軌道は空で表示する。
- 「もう一度」と「武器変更」のボタンがある。
  - 「もう一度」を押すと、同じ武器・同じモードで新しい練習がプレイ画面（`#/play`）で始まる。
  - 「武器変更」を押すと、トップ画面（`#/`）に戻る。
- 保存できない環境（[overview.md](overview.md) の「保存」）でも、リザルト画面はエラーで止まらずに表示され、フッターに保存できないことが表示される。

### 自己ベスト

- 採点するモードで、武器・モード・入力方式ごとに平均ズレが最も小さい結果を自己ベストとして保存する。パターン観察では保存しない。
- 練習が終わったとき、平均ズレが「なし」でなく、次のどちらかに当たれば自己ベストを更新して保存する。
  - 同じ武器・モード・入力方式の自己ベストがまだない。
  - 平均ズレが、保存してある自己ベストの平均ズレより小さい。等しいときは更新しない。
- 自己ベストを更新したら、リザルトに「自己ベスト更新」と表示する。更新しなかったときは、保存してある自己ベストの平均ズレを表示する。
- 自己ベストは入力方式ごとに別のキーで保存し、マウスとパッドの成績を混ぜない（[input.md](input.md)）。
  入力方式の切替がないあいだ、入力方式はマウス（`mouse`）とする。
- 保存はブラウザの localStorage に行う（[overview.md](overview.md) の「保存」）。保存できない環境では、ページを開いているあいだだけ自己ベストが残る。

#### 保存の形

- キーは `apex-training:best:<入力方式>:<武器の id>:<モードの id>`。入力方式は `mouse` か `pad`、武器の id は武器データの `id`
  （例: `r301`）、モードの id はモードのファイルの id（例: `center`）。例: `apex-training:best:mouse:r301:center`。
- 値は次の JSON の文字列。

| 項目 | 型 | 意味 |
|------|----|------|
| `version` | 数値 | 保存の形の版。今は `1` |
| `meanError` | 数値 | 平均ズレ（度） |
| `groupingRadius` | 数値 | グルーピング半径（度） |
| `hitRate` | 数値 | 命中率（%） |
| `shots` | 数値 | 撃った弾数 |
| `achievedAt` | 文字列 | 記録した日時（ISO 8601、UTC） |

- 読み出した値が JSON として読めない、`version` が `1` でない、`meanError` が 0 以上の有限の数でないときは、自己ベストがないものとして扱う。

## 受け入れ条件

- **SCO-1**: 全弾が中心に当たったとき、平均ズレ 0・グルーピング半径 0・命中率 100% と表示される
- **SCO-2**: 前半の弾だけを中心に当て、後半の弾を大きく外したとき、区間ごとのズレで後半が最も大きく表示される
- **SCO-3**: 弾がすべて中心より下に外れたとき、「下げすぎ」のコメントが表示される
- **SCO-4**: リザルト画面で「もう一度」を押したとき、同じ武器・同じモードで練習が始まる
- **SCO-5**: 自己ベストより平均ズレが小さい結果で練習を終えたとき、自己ベストの更新が表示され、再読み込みしても新しい自己ベストが残っている
- **SCO-6**: 30 発のうち前半 10 発のズレを 0、中盤 10 発の水平のズレを 1 度、後半 10 発の水平のズレを 5 度にして採点したとき、区間ごとのズレが前半 0・中盤 1・後半 5 度になる
- **SCO-7**: 28 発を採点したとき、前半に 1〜9 発目、中盤に 10〜18 発目、後半に 19〜28 発目が入る
- **SCO-8**: 全弾の水平のズレを 0、垂直のズレを −2 度にして採点したとき、コメントが「下げすぎ」だけになる
- **SCO-9**: 全弾の水平のズレを 0、垂直のズレを +2 度にして採点したとき、コメントが「下げ不足」だけになる
- **SCO-10**: 全弾の垂直のズレを 0、水平のズレを交互に +1 度・−1 度にして採点したとき、コメントが「横の補正不足」だけになり、横ブレ 1 度・縦ブレ 0 度・比は「なし」になる
- **SCO-11**: 全弾の水平・垂直のズレが 0.4 度以内のとき、コメントが「よくまとまっている」になる
- **SCO-12**: 的の半径を 1 度とし、ズレの大きさが 0.5・1・1.5 度の 3 発を採点したとき、命中率が約 66.7%（3 発中 2 発）になり、平均ズレが 1 度になる
- **SCO-13**: 20 発のうち 19 発のズレを 0、1 発の水平のズレを 10 度にして採点したとき、グルーピング半径が 0.5 度になる（重心が水平 0.5 度にずれ、19 発の距離が 0.5 度）
- **SCO-14**: 1 発も撃たずに採点したとき、すべての指標が「なし」になり、コメントが出ない
- **SCO-15**: リザルト画面で「武器変更」を押したとき、トップ画面に戻る
- **SCO-16**: センター維持またはゴースト追従で練習を終えたとき、リザルト画面に指標とコメント、弾痕の散布図、自分の照準の軌道と理想の軌道の重ね描きが表示される
- **SCO-17**: パターン観察で練習を終えたとき、リザルト画面に指標・コメント・自己ベストが表示されず、弾痕と補正しなかった場合のパターンが重ねて表示され、自己ベストのキーに何も保存されない
- **SCO-18**: 自己ベストがない状態で、マウスで R-301 とセンター維持を練習して終えたとき、「自己ベスト更新」が表示され、`apex-training:best:mouse:r301:center` にその結果の平均ズレが保存される
- **SCO-19**: 保存してある自己ベストより平均ズレが大きい、または等しい結果で練習を終えたとき、「自己ベスト更新」が表示されず、保存してある自己ベストの平均ズレが表示され、保存してある値が変わらない
- **SCO-20**: R-301 とセンター維持の自己ベストがある状態で、R-301 とゴースト追従（または別の武器とセンター維持）を初めて練習して終えたとき、「自己ベスト更新」が表示され、R-301 とセンター維持の自己ベストは変わらない
- **SCO-21**: 自己ベストのキーに JSON として読めない値が入っている状態で練習を終えたとき、エラーで止まらずにリザルト画面が表示され、その結果が自己ベストとして保存される
- **SCO-22**: localStorage への書き込みが例外になる環境で練習を終えたとき、エラーで止まらずにリザルト画面が表示され、フッターに「この環境では設定と記録を保存できません。練習はそのまま続けられます。」と表示される
