# 採点とリザルト

## 概要

各弾の中心からの角度のズレを記録し、まとまり・崩れる位置・ズレの方向を指標にして表示する。
練習が終わるとリザルト画面に指標と弾痕・照準の軌道を表示し、武器・モード・入力方式ごとの自己ベストと練習の履歴を保存する。
履歴の画面（[screens.md](screens.md)）では、武器・モード・入力方式ごとの平均ズレの推移と平均を表示する。
履歴には発の区間（5 発ごと）のズレも保存し、直近の練習から、よく外す発の区間（苦手な区間）とその向きを求めて、
リザルト画面・履歴の画面・練習中の補正のパネルに示す。

## 用語

| 用語 | 意味 |
|------|------|
| 水平のズレ・垂直のズレ | 弾痕の角度のズレ（[weapons.md](weapons.md)）の水平成分 h と垂直成分 v（度）。右と上が正 |
| ズレの大きさ | 中心からの角度の距離 √(h² + v²)（度） |
| 的の半径 | 命中とみなす、中心からの角度の距離の上限（度） |
| 偏りのしきい値 | コメントを出すかどうかを分ける値。0.5 度 |
| 発の区間 | 武器のパターンを発の番号で 5 発ずつに分けたもの。1〜5 発目、6〜10 発目、11〜15 発目、… |
| 苦手な区間 | 直近の練習で、発の区間ごとのズレの大きさの平均がいちばん大きい発の区間（下の「苦手な区間」） |

## 振る舞い

### 採点の入力

- 採点は、撃った順の弾ごとの水平のズレ・垂直のズレ（度）と、的の半径（度）だけから決まる。同じ入力なら同じ結果になる。
- 採点は武器・モード・入力方式によらず同じ計算で行う。

### 指標

n 発の i 発目の水平のズレを hᵢ、垂直のズレを vᵢ、ズレの大きさを dᵢ とする。

| 指標 | 定義 |
|------|------|
| 平均ズレ | dᵢ の平均（度） |
| グルーピング半径 | 弾痕の 95% が入る、弾痕の重心を中心とした円の半径（度） |
| 命中率 | dᵢ が的の半径以下の弾の割合（%） |
| 区間ごとのズレ | 撃った弾を前半・中盤・後半の 3 つに分けた、それぞれの平均ズレ（度） |
| 横ブレと縦ブレ | 横ブレ（\|hᵢ\| の平均、度）と縦ブレ（\|vᵢ\| の平均、度）と、その比（横ブレ ÷ 縦ブレ） |

- グルーピング半径は次の手順で求める。
  1. 重心を（hᵢ の平均, vᵢ の平均）とし、各弾の重心からの距離を求める。
  2. 距離を小さい順に並べ、⌈0.95 × n⌉ 番目（1 から数える）の距離をグルーピング半径とする。
- 命中の判定は的の半径ちょうどを含む（dᵢ = 的の半径なら命中）。
- 区間は撃った順に分ける。k 番目の区間（k = 0 が前半、1 が中盤、2 が後半）には、
  発の番号（0 から数える）が ⌊k × n ÷ 3⌋ 以上 ⌊(k + 1) × n ÷ 3⌋ 未満の弾が入る。
  n が 3 で割り切れないときは、余りの弾が後ろの区間から 1 発ずつ入る（28 発なら 9・9・10 発、29 発なら 9・10・10 発）。
- 弾が 1 発も入らない区間の平均ズレは「なし」とする（n が 3 未満のとき）。
- 縦ブレが 0 のとき、横ブレと縦ブレの比は「なし」とする。
- 1 発も撃たなかったときは、すべての指標を「なし」とし、コメントも出さない。

### コメント

- 垂直のズレの平均（vᵢ の平均、符号つき）と横ブレから、次の表のコメントを選ぶ。縦と横で 1 つずつ、合わせて最大 2 つを、
  縦・横の順に表示する。

| 条件 | コメント |
|------|---------|
| 垂直のズレの平均が −0.5 度以下（弾が中心より下に寄っている） | 下げすぎ |
| 垂直のズレの平均が +0.5 度以上（弾が中心より上に寄っている） | 下げ不足 |
| 横ブレが 0.5 度以上 | 横の補正不足 |
| 上のどれにも当たらない | よくまとまっている |

- しきい値ちょうど（−0.5 度、+0.5 度、0.5 度）は条件に当たるものとする。

### リザルト画面

- 練習が終わると、その練習の武器・モード・入力方式・弾痕の記録・入力の記録（[input.md](input.md)）と採点結果を受け取って表示する。
- すべてのモード（今は反復練習、[modes.md](modes.md)）で採点し、次を表示する。
  - 指標（平均ズレ・グルーピング半径・命中率・区間ごとのズレ・横ブレと縦ブレと比）とコメント。「なし」の指標は「なし」と表示する。
  - 弾痕の散布図。各弾の水平のズレ・垂直のズレ（度）を、中心を原点に右と上を正として点で描き、的の半径の円を重ねる。
  - 自分の照準の軌道と理想の軌道（[weapons.md](weapons.md) の理想の補正軌道）の重ね描き。自分の照準の軌道は入力の記録から求めた、
    各弾の発射時の照準（開始時の照準からのヨー・ピッチ、度）を撃った順に結んだ線で、理想の軌道は 1 発目から撃った弾数までの理想の補正軌道を結んだ線。
  - 自己ベスト（下の「自己ベスト」）。
  - 練習の入力方式がパッドのときだけ、右スティックの入力推移のグラフと使ったパッドの名前（[pad.md](pad.md)「パッド向けのガイド」）。
  - 苦手な区間の 1 行（下の「苦手な区間」）。今の練習を履歴に足したあとの履歴から求め、
    「この武器の苦手な区間: 11〜15 発目、右に外しがち」の形で表示する。苦手な区間が「なし」のときは、この行を表示しない。
- 1 発も撃たずに終わることはない（[modes.md](modes.md)）が、弾が 1 発もない結果を渡されたときは、指標を「なし」と表示し、散布図と軌道は空で表示する。
- 「もう一度」と「武器変更」のボタンがある。
  - 「もう一度」を押すと、同じ武器・同じモードで新しい練習がプレイ画面（`#/play`）で始まる。
  - 「武器変更」を押すと、トップ画面（`#/`）に戻る。
  - どちらもキーボードとパッドのボタンでも操作できる（[screens.md](screens.md)「画面の操作」）。
- 「結果をシェア」のボタンと「X に投稿」のリンクがあり、成績の要約の文をシェアできる（[screens.md](screens.md)「結果のシェア」）。
- 回数が 1 のときにリザルト画面を表示する。連続練習（[modes.md](modes.md)「連続練習（セット）」）では、各回の終わりに短いリザルトを、
  セットの終わりにセットのまとめ（[screens.md](screens.md)「セットのまとめ」）を表示する。
- 保存できない環境（[overview.md](overview.md) の「保存」）でも、リザルト画面はエラーで止まらずに表示され、フッターに保存できないことが表示される。

### 自己ベスト

- 武器・モード・入力方式ごとに平均ズレが最も小さい結果を自己ベストとして保存する。
- 練習が終わったとき、平均ズレが「なし」でなく、次のどちらかに当たれば自己ベストを更新して保存する。
  - 同じ武器・モード・入力方式の自己ベストがまだない。
  - 平均ズレが、保存してある自己ベストの平均ズレより小さい。等しいときは更新しない。
- 連続練習では、回が終わるごとに上の判定を行う。やり直しやセットの中断で打ち切った回は判定しない。
- 自己ベストを更新したら、リザルトに「自己ベスト更新」と表示する。連続練習の短いリザルトでも、その回で更新したときは「自己ベスト更新」と表示する。更新しなかったときは、保存してある自己ベストの平均ズレを表示する。
- 自己ベストは入力方式ごとに別のキーで保存し、マウスとパッドの成績を混ぜない（[input.md](input.md)）。
  比べて保存するのは練習の入力方式（その練習の 1 発目を撃ったときの入力方式、[input.md](input.md)「入力方式ごとの保存」）の自己ベストで、
  リザルトにはその入力方式の自己ベストだけを表示する。
- 保存はブラウザの localStorage に行う（[overview.md](overview.md) の「保存」）。保存できない環境では、ページを開いているあいだだけ自己ベストが残る。

#### 保存の形

- キーは `apex-training:best:<入力方式>:<武器の id>:<モードの id>`。入力方式は `mouse` か `pad`、武器の id は武器データの `id`
  （例: `lstar`）、モードの id はモードのファイルの id（反復練習は `ghost`）。例: `apex-training:best:mouse:lstar:ghost`。
- 登録されていないモードの id（以前のセンター維持の `center`、パターン観察の `pattern` など）の自己ベストが保存してあっても、エラーにせず、読まず、消さない（[modes.md](modes.md)「モードの登録」）。
- 値は次の JSON の文字列。

| 項目 | 型 | 意味 |
|------|----|------|
| `version` | 数値 | 保存の形の版。今は `1` |
| `meanError` | 数値 | 平均ズレ（度） |
| `groupingRadius` | 数値 | グルーピング半径（度） |
| `hitRate` | 数値 | 命中率（%） |
| `shots` | 数値 | 撃った弾数 |
| `achievedAt` | 文字列 | 記録した日時（ISO 8601、UTC） |

- 読み出した値が JSON として読めない、`version` が `1` でない、`meanError` が 0 以上の有限の数でないときは、自己ベストがないものとして扱う。

### 練習の履歴

- 練習が終わるたびに、平均ズレが「なし」でなければ、その結果を 1 件として
  武器・モード・入力方式ごとの履歴の最後に足して保存する。平均ズレが「なし」の結果は足さない。
  連続練習（[modes.md](modes.md)「連続練習（セット）」）では回ごとに 1 件を足す。やり直しやセットの中断で打ち切った回は足さない。
- 1 件には、終えた日時・平均ズレ・命中率・グルーピング半径・撃った弾数と、発の区間ごとのズレ（下の「発の区間ごとのズレ」）を持つ。
  武器・モード・入力方式は保存のキーで分ける。
- 履歴は武器・モード・入力方式の組ごとに直近 200 件まで保存する。201 件目を足すときは、その組の最も古い 1 件を消す。
  ほかの組の履歴は変わらない。
- 履歴は自己ベストとは別に保存する。履歴を消しても自己ベストは変わらず、自己ベストの更新は履歴に影響しない。
- 入力方式は自己ベストと同じく `mouse` か `pad` で、マウスとパッドの履歴を混ぜない。
- 保存はブラウザの localStorage に行う（[overview.md](overview.md) の「保存」）。保存できない環境でも練習とリザルト画面はエラーで止まらず、
  履歴はページを開いているあいだだけ残る。
- 履歴をファイルに書き出す操作や、外部へ送る操作はない（[overview.md](overview.md) の OVR-5）。

#### 履歴の平均

組の履歴の、古い順に 1 から数えた番号を「回」とする（上限で古いものが消えたあとは、残っている最も古い件が 1 回目）。

| 平均 | 定義 |
|------|------|
| 今日の平均 | 終えた日時がブラウザの時間帯で今日の日付に当たる件の平均ズレの平均（度） |
| 直近 10 回の平均 | 新しい順に最大 10 件の平均ズレの平均（度）。10 件未満のときはあるだけの件で求める |
| 全体の平均 | 保存してあるすべての件の平均ズレの平均（度） |

- 当たる件が 1 件もない平均は「なし」とする。

#### 発の区間ごとのズレ

- 発の区間は、発の番号（1 から数える）で 5 発ずつに分ける。j 番目の発の区間（j = 1, 2, …）には (5j − 4)〜5j 発目が入る。
  採点の指標の「区間ごとのズレ」（前半・中盤・後半の 3 つ）とは別のもので、撃った弾数によらず同じ発の番号は同じ発の区間に入る。
- 練習ごとに、1 発以上が入る発の区間のそれぞれについて、次を求めて履歴の 1 件に持つ。
  - 弾数: その発の区間に入る弾の数（1〜5）。撃った弾数が 5 の倍数でないときは、最後の発の区間の弾数が 5 未満になる（23 発なら 21〜23 発目の 3 発）。
  - 水平のズレの平均（hᵢ の平均、符号つき、度）と垂直のズレの平均（vᵢ の平均、符号つき、度）。
  - ズレの大きさの平均（dᵢ の平均、度）。
- 弾が 1 発も入らない発の区間は持たない。

#### 苦手な区間

- 苦手な区間は、武器・モード・入力方式の組ごとに、その組の履歴から求める。登録されていないモードの id（以前のセンター維持など）の履歴は、
  同じ武器・入力方式でも使わない。
- 対象は、その組の履歴のうち、発の区間ごとのズレを持つ件の新しい順に 5 件（直近 5 回）。発の区間ごとのズレを持たない件
  （古い形式の件や、読めない件）は数えず、エラーにもしない。対象が 5 件に満たないときは、苦手な区間は「なし」とする。
- 発の区間ごとに、対象の 5 件のその発の区間を弾数で重み付けして合わせ、水平のズレの平均・垂直のズレの平均・ズレの大きさの平均を求める
  （各件の「平均 × 弾数」の合計 ÷ 弾数の合計）。対象の 5 件のうち 3 件以上にその発の区間があるものだけを比べる対象にする。
- 比べる対象の発の区間のうち、ズレの大きさの平均がいちばん大きい発の区間を苦手な区間とする。いちばん大きい発の区間が複数あるときは、発の番号の小さい方とする。
  いちばん大きいズレの大きさの平均が偏りのしきい値（0.5 度）未満のとき、また比べる対象の発の区間が 1 つもないときは、苦手な区間は「なし」とする。
- 苦手な区間の向きは、その発の区間の垂直のズレの平均と水平のズレの平均から、次の表で縦と横に 1 つずつ選び、縦・横の順に「・」でつなぐ。
  しきい値ちょうどは条件に当たるものとする。

| 条件 | 向き |
|------|------|
| 垂直のズレの平均が +0.5 度以上 | 上に外しがち（下げ不足） |
| 垂直のズレの平均が −0.5 度以下 | 下に外しがち（下げすぎ） |
| 水平のズレの平均が +0.5 度以上 | 右に外しがち |
| 水平のズレの平均が −0.5 度以下 | 左に外しがち |
| 上のどれにも当たらない | 向きが定まらない |

- 苦手な区間は「<最初の発>〜<最後の発> 発目、<向き>」の形で表す（例: 「11〜15 発目、右に外しがち」「1〜5 発目、上に外しがち（下げ不足）・右に外しがち」）。
  最後の発は 5j とする（23 発の練習だけでも「21〜25 発目」と表す）。
- 苦手な区間は表示だけに使い、ファイルへの書き出しや外部へ送る操作はない（[overview.md](overview.md) の OVR-5）。

#### 履歴の保存の形

- キーは `apex-training:history:<入力方式>:<武器の id>:<モードの id>`。例: `apex-training:history:mouse:lstar:ghost`。
- 登録されていないモードの id の履歴が保存してあっても、エラーにせず、表示にも苦手な区間にも使わず、消さない。
- 値は次の JSON の文字列。

| 項目 | 型 | 意味 |
|------|----|------|
| `version` | 数値 | 保存の形の版。今は `1` |
| `entries` | 配列 | 1 件ずつの記録。古い順に並ぶ |

- `entries` の各要素は次の項目を持つ。

| 項目 | 型 | 意味 |
|------|----|------|
| `at` | 文字列 | 終えた日時（ISO 8601、UTC） |
| `meanError` | 数値 | 平均ズレ（度） |
| `hitRate` | 数値 | 命中率（%） |
| `groupingRadius` | 数値 | グルーピング半径（度） |
| `shots` | 数値 | 撃った弾数 |
| `sections` | 配列 | 発の区間ごとのズレ。発の番号の順に並ぶ。持たない件もある（古い形式の件） |

- `sections` の各要素は次の項目を持つ。

| 項目 | 型 | 意味 |
|------|----|------|
| `start` | 数値 | 発の区間の最初の発の番号（1, 6, 11, …） |
| `shots` | 数値 | その発の区間の弾数（1〜5） |
| `meanH` | 数値 | 水平のズレの平均（度、符号つき） |
| `meanV` | 数値 | 垂直のズレの平均（度、符号つき） |
| `meanError` | 数値 | ズレの大きさの平均（度） |

- 読み出した値が JSON として読めない、`version` が `1` でない、`entries` が配列でないときは、その組の履歴が空として扱う。
- `entries` のうち、`at` が日時として読めない、または `meanError` が 0 以上の有限の数でない要素は読み飛ばし、ほかの要素はそのまま使う。
- `sections` がない、配列でない、またはその要素のどれかが上の形に合わない（`start` が 5 で割って 1 余る 1 以上の整数でない、`shots` が 1〜5 の整数でない、
  `meanH`・`meanV` が有限の数でない、`meanError` が 0 以上の有限の数でない、`start` が重なる）件は、発の区間ごとのズレを持たない件として扱う。
  その件はほかの項目をそのまま使い、平均ズレの推移・履歴の平均・一覧には入る。
- 次に練習を終えて保存するときは、読み飛ばした要素を除いた履歴に足して書き直す。発の区間ごとのズレを持たない件は、そのまま書き直す。

## 受け入れ条件

- **SCO-1**: 全弾が中心に当たったとき、平均ズレ 0・グルーピング半径 0・命中率 100% と表示される
- **SCO-2**: 前半の弾だけを中心に当て、後半の弾を大きく外したとき、区間ごとのズレで後半が最も大きく表示される
- **SCO-3**: 弾がすべて中心より下に外れたとき、「下げすぎ」のコメントが表示される
- **SCO-4**: リザルト画面で「もう一度」を押したとき、同じ武器・同じモードで練習が始まる
- **SCO-5**: 自己ベストより平均ズレが小さい結果で練習を終えたとき、自己ベストの更新が表示され、再読み込みしても新しい自己ベストが残っている
- **SCO-6**: 30 発のうち前半 10 発のズレを 0、中盤 10 発の水平のズレを 1 度、後半 10 発の水平のズレを 5 度にして採点したとき、区間ごとのズレが前半 0・中盤 1・後半 5 度になる
- **SCO-7**: 28 発を採点したとき、前半に 1〜9 発目、中盤に 10〜18 発目、後半に 19〜28 発目が入る
- **SCO-8**: 全弾の水平のズレを 0、垂直のズレを −2 度にして採点したとき、コメントが「下げすぎ」だけになる
- **SCO-9**: 全弾の水平のズレを 0、垂直のズレを +2 度にして採点したとき、コメントが「下げ不足」だけになる
