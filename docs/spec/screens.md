# 画面と設定

## 概要

3D のキャンバスの上に、HTML の画面（トップ・設定・リザルト）を重ねる。画面はハッシュで切り替える。

## 振る舞い

### 画面

| 画面 | ハッシュ | 内容 |
|------|---------|------|
| トップ | `#/` | 武器の選択（種類別）、モードの選択、「開始」 |
| 設定 | `#/settings` | 下記の設定項目 |
| プレイ | `#/play` | 全画面のキャンバスと HUD（[modes.md](modes.md)） |
| リザルト | `#/result` | 指標と散布図（[scoring.md](scoring.md)） |
| パッドのキャリブレーション | `#/settings/pad` | スティックとボタンの生の値（[pad.md](pad.md)） |

- 練習中でない状態で `#/play` や `#/result` を直接開いたときは、トップ画面を表示する。

### 設定項目

| 区分 | 項目 |
|------|------|
| 共通 | 入力方式（マウス / パッド / 自動）、FOV、クロスヘアの色と形、ゴースト表示（ON/OFF）、音（ON/OFF） |
| マウス | DPI、感度、ADS 倍率（cm/360 を表示） |
| パッド | 簡易設定 / 詳細設定（ALC 相当）、振動（ON/OFF）、ボタン割り当て、キャリブレーションへのリンク |

- 設定は変えるとすぐに保存され、次に開いたときも残っている。

### FOV と画面への投影

- FOV は Apex の設定画面の値として入力する。角度から画面上の位置への換算はこの FOV から求めた水平視野角で行い、
  同じ角度のズレは、FOV が広いほど画面上で小さく表示される。
- Apex の FOV の値から水平視野角への正確な換算式は未確認（[docs/roadmap.md](../roadmap.md)）。

## 受け入れ条件

- **UI-1**: トップ画面で武器とモードを選んで「開始」を押したとき、プレイ画面になり、選んだ武器名が HUD に表示される
- **UI-2**: 設定画面で感度を変えて再読み込みしたとき、変えた感度が残っている
- **UI-3**: 練習中でない状態で `#/result` を直接開いたとき、トップ画面が表示される
- **UI-4**: ゴースト表示を OFF にしてゴースト追従を始めたとき、ゴーストが表示されない
- **UI-5**: 同じ角度のズレの弾痕が、FOV を広くしたときに画面上でより中心に近く表示される
